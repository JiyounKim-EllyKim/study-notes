# 🎄 Advent of SQL 2024

SolveSQL의 **Advent of SQL 2024** 문제 풀이 기록입니다.

## 📌 Progress

- 총 25문제 완료
- 25번은 단순 문자열 출력 문제로 별도 풀이 파일에서는 제외
- 각 문제는 직접 작성한 풀이를 기준으로 정리
- 검색이나 강의를 참고한 부분은 풀이 기록에 별도로 표시

## 🧠 Study Method

문제를 푼 뒤 다음 내용을 함께 기록했습니다.

- 직접 작성한 SQL 쿼리
- 문제 해결에 사용한 핵심 개념
- 강의 풀이와의 차이
- 새롭게 알게 된 문법이나 함수
- 풀이 과정에서 막혔던 부분

새로운 개념이 쌓이면 `../../theory/` 폴더의 개념 노트에 추가했습니다.

## 📚 Topics

문제 풀이를 통해 다음 내용을 연습했습니다.

- GROUP BY / HAVING
- JOIN / SELF JOIN
- Subquery / CTE
- CASE WHEN
- UNION / UNION ALL
- Window Function
- 누적 합계 / 이동 평균 / 중앙값
- 문자열 및 날짜 함수
- 연속 구간 및 세션 분석
