# 📌 SQL

## 🧭 Overview

데이터 조회 및 분석에 필요한 SQL 문법과 쿼리 작성 과정을 정리한 공간입니다.

기본 조회 문법부터 JOIN, 서브쿼리, CTE, 윈도우 함수까지 학습하며,
문제 풀이 과정에서 새롭게 익힌 개념은 `theory/`에 정리하고 있습니다.

---

## 📚 Topics Covered

- SELECT / WHERE / DISTINCT
- ORDER BY / GROUP BY / HAVING
- JOIN / SELF JOIN
- Subquery / CTE
- UNION / UNION ALL
- Window Function
- 문자열 및 날짜 함수
- 조건부 집계와 NULL 처리
