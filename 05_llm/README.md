## Key Concepts

* LLM은 대규모 텍스트 데이터로 학습된 언어 모델입니다.
* LLM은 주어진 문맥을 바탕으로 다음에 올 토큰을 예측하는 방식으로 동작합니다.
* Prompt는 LLM에게 작업 지시와 필요한 맥락을 전달하는 입력입니다.
* Embedding은 텍스트의 의미를 벡터로 표현하는 방법입니다.
* Vector DB는 Embedding 벡터를 저장하고 유사도 검색을 수행하는 데 사용됩니다.
* RAG는 외부 문서를 검색하여 LLM의 답변에 근거를 제공하는 방식입니다.
* Fine-tuning은 사전학습된 모델을 특정 작업이나 도메인에 맞게 추가 학습하는 방법입니다.
* Agent는 LLM이 도구를 사용하거나 여러 단계를 거쳐 작업을 수행하도록 구성한 시스템입니다.

## Insights

* LLM은 단순한 텍스트 생성 모델을 넘어 검색, 요약, 질의응답, 문서 분석, 코드 생성 등 다양한 작업에 활용됩니다.
* LLM 활용에서는 모델 자체뿐만 아니라 Prompt, 검색 구조, 데이터 품질, 평가 방식이 중요합니다.
* RAG는 모델이 모르는 외부 정보를 검색해 답변에 활용하도록 만드는 대표적인 LLM 애플리케이션 구조입니다.
* Agent는 LLM이 단순 답변을 넘어 도구 사용과 단계적 의사결정을 수행하도록 확장한 방식입니다.
* LLM 결과는 항상 정확하다고 볼 수 없으므로 Hallucination, 근거 확인, 평가 체계를 함께 고려해야 합니다.
