# Activation Function 개념 정리

## 1. Activation Function

Activation Function은 뉴런의 출력값을 결정하는 함수이다.

신경망에서 각 뉴런은 입력값에 가중치를 곱하고 편향을 더한 뒤, 그 결과를 활성화 함수에 통과시킨다.

$$
z = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b
$$

$$
a = f(z)
$$

* $z$: 선형 결합 결과
* $f(z)$: 활성화 함수
* $a$: 활성화 함수 적용 후 출력값

---

## 2. 활성화 함수가 필요한 이유

활성화 함수가 없다면 신경망은 여러 층을 쌓아도 결국 하나의 선형 모델과 비슷하게 동작한다.

즉, 복잡한 비선형 관계를 학습하기 어렵다.

활성화 함수는 신경망에 비선형성을 추가하여, 복잡한 패턴을 학습할 수 있도록 만든다.

---

## 3. Step Function 계단 함수

Step Function은 입력값이 특정 기준 이상이면 1, 그렇지 않으면 0을 출력하는 함수이다.

$$
f(z) =
\begin{cases}
1, & z \geq 0 \
0, & z < 0
\end{cases}
$$

### 특징

* 초기 퍼셉트론에서 사용되었다.
* 출력값이 0 또는 1이다.
* 이진 분류처럼 단순한 판단에 사용할 수 있다.
* 값이 불연속적이므로 딥러닝 학습에는 잘 사용되지 않는다.

---

## 4. Sigmoid Function

Sigmoid 함수는 입력값을 0과 1 사이의 값으로 변환한다.

$$
\sigma(z) = \frac{1}{1 + e^{-z}}
$$

### 특징

* 출력값이 항상 0과 1 사이이다.
* 확률처럼 해석할 수 있다.
* 이진 분류의 출력층에서 자주 사용된다.
* 입력값이 매우 크거나 작으면 기울기가 거의 0에 가까워진다.
* 기울기 소실 Vanishing Gradient 문제가 발생할 수 있다.

### 사용 예시

| 문제 유형 | 사용 위치 |
| ----- | ----- |
| 이진 분류 | 출력층   |

---

## 5. Tanh Function

Tanh 함수는 입력값을 -1과 1 사이의 값으로 변환한다.

$$
tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}
$$

### 특징

* 출력값이 -1과 1 사이이다.
* Sigmoid보다 출력 중심이 0에 가까워 학습이 더 안정적일 수 있다.
* 하지만 입력값이 매우 크거나 작으면 기울기 소실 문제가 발생할 수 있다.

### 사용 예시

| 문제 유형      | 사용 위치 |
| ---------- | ----- |
| 순환 신경망 RNN | 은닉층   |

---

## 6. ReLU Function

ReLU는 Rectified Linear Unit의 약자이다.

입력값이 0보다 작으면 0을 출력하고, 0보다 크면 입력값을 그대로 출력한다.

$$
ReLU(z) = \max(0, z)
$$

### 특징

* 계산이 단순하다.
* 양수 영역에서는 기울기가 유지되어 학습이 빠르다.
* 은닉층에서 가장 많이 사용되는 활성화 함수 중 하나이다.
* 음수 입력에 대해서는 항상 0을 출력한다.
* 일부 뉴런이 더 이상 학습되지 않는 Dying ReLU 문제가 발생할 수 있다.

### 사용 예시

| 문제 유형       | 사용 위치 |
| ----------- | ----- |
| 일반적인 딥러닝 모델 | 은닉층   |
| CNN         | 은닉층   |

---

## 7. Leaky ReLU

Leaky ReLU는 ReLU의 Dying ReLU 문제를 완화하기 위해 만들어진 함수이다.

음수 입력에 대해서도 아주 작은 기울기를 허용한다.

$$
LeakyReLU(z) =
\begin{cases}
z, & z > 0 \
\alpha z, & z \leq 0
\end{cases}
$$

일반적으로 $\alpha$는 0.01처럼 작은 값을 사용한다.

### 특징

* 음수 영역에서도 작은 값을 출력한다.
* ReLU보다 뉴런이 완전히 죽는 문제를 줄일 수 있다.
* ReLU의 대안으로 사용할 수 있다.

---

## 8. Softmax Function

Softmax 함수는 여러 클래스에 대한 점수를 확률로 변환하는 함수이다.

$$
softmax(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}
$$

* $z_i$: i번째 클래스의 점수
* $K$: 전체 클래스 개수

### 특징

* 각 클래스에 대한 확률을 출력한다.
* 모든 클래스의 확률 합은 1이다.
* 다중 분류의 출력층에서 사용된다.
* 가장 높은 확률을 가진 클래스를 최종 예측값으로 선택한다.

### 사용 예시

| 문제 유형 | 사용 위치 |
| ----- | ----- |
| 다중 분류 | 출력층   |

---

## 9. 활성화 함수 선택 기준

| 문제 유형 | 출력층 활성화 함수      | 설명            |
| ----- | --------------- | ------------- |
| 회귀    | 사용하지 않거나 Linear | 연속형 값을 그대로 예측 |
| 이진 분류 | Sigmoid         | 클래스 1일 확률 출력  |
| 다중 분류 | Softmax         | 클래스별 확률 출력    |

은닉층에서는 주로 ReLU 계열 함수를 많이 사용한다.

| 사용 위치     | 주로 사용하는 함수       |
| --------- | ---------------- |
| 은닉층       | ReLU, Leaky ReLU |
| 이진 분류 출력층 | Sigmoid          |
| 다중 분류 출력층 | Softmax          |
| 회귀 출력층    | Linear           |

---

## 10. 활성화 함수 비교

| 함수            | 출력 범위       | 주요 사용     |
| ------------- | ----------- | --------- |
| Step Function | 0 또는 1      | 초기 퍼셉트론   |
| Sigmoid       | 0 ~ 1       | 이진 분류 출력층 |
| Tanh          | -1 ~ 1      | RNN, 은닉층  |
| ReLU          | 0 이상        | 일반적인 은닉층  |
| Leaky ReLU    | 음수 일부 허용    | ReLU 대안   |
| Softmax       | 0 ~ 1, 합은 1 | 다중 분류 출력층 |

---

## 11. 정리

* 활성화 함수는 뉴런의 출력값을 결정하는 함수이다.
* 신경망이 비선형 관계를 학습하려면 활성화 함수가 필요하다.
* Sigmoid는 이진 분류 출력층에서 자주 사용된다.
* Softmax는 다중 분류 출력층에서 자주 사용된다.
* ReLU는 은닉층에서 가장 많이 사용되는 활성화 함수 중 하나이다.
* Leaky ReLU는 ReLU의 Dying ReLU 문제를 완화하기 위한 대안이다.
* 문제 유형과 층의 위치에 따라 적절한 활성화 함수를 선택해야 한다.
