# Neural Network 개념 정리

## 1. Neural Network

Neural Network는 사람의 신경망 구조에서 아이디어를 얻은 모델로, 여러 개의 노드가 연결되어 입력 데이터의 패턴을 학습하는 구조이다.

딥러닝 모델은 여러 층의 신경망을 쌓아 복잡한 비선형 관계를 학습할 수 있다.

---

## 2. 기본 구조

신경망은 보통 다음과 같은 층으로 구성된다.

| 구성 요소            | 설명                      |
| ---------------- | ----------------------- |
| 입력층 Input Layer  | 데이터를 입력받는 층             |
| 은닉층 Hidden Layer | 입력 데이터를 변환하고 패턴을 학습하는 층 |
| 출력층 Output Layer | 최종 예측값을 출력하는 층          |

입력층에서 들어온 데이터는 은닉층을 거치며 여러 가중치와 활성화 함수를 통과하고, 마지막 출력층에서 예측 결과로 변환된다.

---

## 3. 뉴런 Neuron

뉴런은 신경망을 구성하는 기본 단위이다.

각 뉴런은 입력값을 받아 가중치를 곱하고, 편향을 더한 뒤 활성화 함수를 적용한다.

$$
z = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b
$$

* $x_i$: 입력값
* $w_i$: 가중치
* $b$: 편향
* $z$: 선형 결합 결과

이후 $z$는 활성화 함수를 통과하여 다음 층으로 전달된다.

---

## 4. 가중치와 편향

### 4.1. 가중치 Weight

가중치는 입력값이 결과에 얼마나 영향을 미치는지를 나타내는 값이다.

학습 과정에서 모델은 손실을 줄이는 방향으로 가중치를 조정한다.

### 4.2. 편향 Bias

편향은 입력값과 별도로 더해지는 값이다.

편향을 사용하면 모델이 더 다양한 형태의 관계를 표현할 수 있다.

---

## 5. 활성화 함수 Activation Function

활성화 함수는 뉴런의 출력값을 변환하는 함수이다.

선형 결합만 사용하면 여러 층을 쌓아도 결국 하나의 선형 모델과 비슷해진다.
따라서 신경망이 비선형 관계를 학습하려면 활성화 함수가 필요하다.

대표적인 활성화 함수는 다음과 같다.

| 함수      | 특징                   |
| ------- | -------------------- |
| Sigmoid | 0과 1 사이의 값으로 변환      |
| Tanh    | -1과 1 사이의 값으로 변환     |
| ReLU    | 0보다 작으면 0, 크면 그대로 출력 |
| Softmax | 다중 분류에서 클래스별 확률로 변환  |

---

## 6. 출력층의 활성화 함수

문제 유형에 따라 출력층에서 사용하는 활성화 함수가 달라진다.

| 문제 유형 | 출력층 활성화 함수 | 설명              |
| ----- | ---------- | --------------- |
| 회귀    | 보통 사용하지 않음 | 연속형 값을 그대로 예측   |
| 이진 분류 | Sigmoid    | 클래스 1일 확률 출력    |
| 다중 분류 | Softmax    | 각 클래스에 속할 확률 출력 |

---

## 7. 손실 함수 Loss Function

손실 함수는 모델의 예측값과 실제값의 차이를 측정하는 함수이다.

모델은 학습 과정에서 손실 함수 값을 줄이는 방향으로 가중치와 편향을 업데이트한다.

대표적인 손실 함수는 다음과 같다.

| 문제 유형 | 손실 함수                                         |
| ----- | --------------------------------------------- |
| 회귀    | MSE, MAE                                      |
| 이진 분류 | Binary Cross Entropy                          |
| 다중 분류 | Categorical Cross Entropy, Cross Entropy Loss |

---

## 8. 학습 과정

신경망의 학습 과정은 대략 다음과 같다.

1. 입력 데이터를 신경망에 넣는다.
2. 각 층에서 가중치, 편향, 활성화 함수를 통해 값을 계산한다.
3. 출력층에서 예측값을 만든다.
4. 손실 함수를 이용해 실제값과 예측값의 차이를 계산한다.
5. 역전파를 통해 각 가중치가 손실에 미친 영향을 계산한다.
6. 옵티마이저를 사용해 가중치와 편향을 업데이트한다.
7. 이 과정을 반복하면서 손실을 줄인다.

---

## 9. 순전파 Forward Propagation

순전파는 입력 데이터가 입력층에서 출력층 방향으로 전달되며 예측값을 계산하는 과정이다.

즉, 현재 가중치와 편향을 사용해 모델이 예측을 수행하는 단계이다.

---

## 10. 역전파 Backpropagation

역전파는 출력층에서 계산된 손실을 기준으로, 각 가중치가 손실에 얼마나 영향을 주었는지 계산하는 과정이다.

이 값을 이용해 모델은 손실을 줄이는 방향으로 가중치를 업데이트한다.

역전파는 딥러닝 모델 학습의 핵심 과정이다.

---

## 11. 옵티마이저 Optimizer

옵티마이저는 손실 함수 값을 줄이기 위해 가중치와 편향을 어떻게 업데이트할지 정하는 알고리즘이다.

대표적인 옵티마이저는 다음과 같다.

| 옵티마이저    | 특징                        |
| -------- | ------------------------- |
| SGD      | 기본적인 경사하강법 방식             |
| Momentum | 이전 업데이트 방향을 반영            |
| RMSProp  | 학습률을 변수별로 조정              |
| Adam     | Momentum과 RMSProp의 장점을 결합 |

---

## 12. Epoch, Batch, Iteration

딥러닝 학습에서는 데이터 전체를 한 번에 학습하지 않고, 여러 묶음으로 나누어 반복 학습한다.

| 용어        | 의미                       |
| --------- | ------------------------ |
| Epoch     | 전체 학습 데이터를 한 번 모두 학습한 횟수 |
| Batch     | 한 번에 학습에 사용하는 데이터 묶음     |
| Iteration | 한 Batch를 학습한 횟수          |

예를 들어 학습 데이터가 1000개이고 Batch Size가 100이면, 1 Epoch에는 10번의 Iteration이 발생한다.

---

## 13. 과대적합 Overfitting

딥러닝 모델은 표현력이 강하기 때문에 학습 데이터에 지나치게 맞춰지는 과대적합이 발생할 수 있다.

과대적합을 줄이기 위한 방법은 다음과 같다.

* 데이터 증가
* Dropout
* Regularization
* Early Stopping
* Batch Normalization
* 모델 구조 단순화

---

## 14. 정리

* Neural Network는 여러 뉴런과 층을 이용해 데이터의 패턴을 학습하는 모델이다.
* 신경망은 입력층, 은닉층, 출력층으로 구성된다.
* 뉴런은 입력값에 가중치를 곱하고 편향을 더한 뒤 활성화 함수를 적용한다.
* 활성화 함수는 신경망이 비선형 관계를 학습할 수 있도록 한다.
* 손실 함수는 예측값과 실제값의 차이를 측정한다.
* 순전파는 예측값을 계산하는 과정이다.
* 역전파는 손실을 줄이기 위해 가중치를 업데이트하는 과정이다.
* 옵티마이저는 가중치 업데이트 방법을 결정한다.
* 딥러닝 모델은 과대적합에 주의해야 한다.
