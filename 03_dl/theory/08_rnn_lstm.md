# RNN / LSTM 개념 정리

## 1. RNN

RNN은 Recurrent Neural Network의 약자로, 순서가 있는 데이터를 처리하기 위한 신경망이다.

한국어로는 순환 신경망이라고 한다.

일반적인 신경망은 각 입력을 독립적으로 처리하지만, RNN은 이전 시점의 정보를 현재 시점의 계산에 함께 사용한다.

따라서 문장, 음성, 시계열 데이터처럼 순서가 중요한 데이터에 사용할 수 있다.

---

## 2. RNN이 사용되는 이유

순서가 있는 데이터는 앞뒤 맥락이 중요하다.

예를 들어 문장에서 단어의 의미는 앞에 어떤 단어가 나왔는지에 따라 달라질 수 있다.

```text id="b56tim"
나는 오늘 학교에 갔다.
나는 오늘 병원에 갔다.
```

같은 “갔다”라는 단어도 앞의 단어에 따라 문장의 의미가 달라진다.

RNN은 이전 시점의 정보를 기억하면서 현재 입력을 처리할 수 있기 때문에 순차 데이터에 적합하다.

---

## 3. RNN의 기본 구조

RNN은 현재 입력값과 이전 시점의 은닉 상태를 함께 사용하여 현재 시점의 은닉 상태를 계산한다.

```text id="e2je7i"
x1 → RNN → h1
x2 → RNN → h2
x3 → RNN → h3
```

각 시점에서 계산된 은닉 상태는 다음 시점으로 전달된다.

---

## 4. Hidden State

Hidden State는 RNN이 이전 시점까지의 정보를 저장하는 값이다.

현재 시점의 은닉 상태는 현재 입력값과 이전 은닉 상태를 이용해 계산된다.

$$
h_t = f(W_x x_t + W_h h_{t-1} + b)
$$

* $x_t$: 현재 시점의 입력값
* $h_t$: 현재 시점의 은닉 상태
* $h_{t-1}$: 이전 시점의 은닉 상태
* $W_x$: 입력값에 대한 가중치
* $W_h$: 이전 은닉 상태에 대한 가중치
* $b$: 편향
* $f$: 활성화 함수

---

## 5. RNN의 학습 방식

RNN은 시간 순서에 따라 데이터를 처리한다.

1. 첫 번째 입력을 받는다.
2. 은닉 상태를 계산한다.
3. 다음 입력을 받을 때 이전 은닉 상태를 함께 사용한다.
4. 이 과정을 마지막 시점까지 반복한다.
5. 최종 출력과 실제값의 차이를 계산한다.
6. 역전파를 통해 가중치를 업데이트한다.

RNN에서는 시간 방향으로 펼쳐진 구조에 대해 역전파를 수행한다.
이를 BPTT Backpropagation Through Time이라고 한다.

---

## 6. RNN의 활용 예시

RNN은 순서가 중요한 데이터에 사용할 수 있다.

| 분야     | 예시                      |
| ------ | ----------------------- |
| 자연어 처리 | 문장 분류, 감성 분석, 번역        |
| 시계열 예측 | 주가 예측, 수요 예측, 센서 데이터 분석 |
| 음성 처리  | 음성 인식, 음성 생성            |
| 텍스트 생성 | 다음 단어 예측, 문장 생성         |

---

## 7. RNN의 한계

RNN은 이전 정보를 활용할 수 있지만, 긴 시퀀스를 처리할 때 한계가 있다.

시퀀스가 길어질수록 앞쪽 정보가 뒤쪽까지 잘 전달되지 않을 수 있다.

대표적인 문제가 기울기 소실 Vanishing Gradient 문제이다.

---

## 8. Vanishing Gradient 문제

RNN은 시간 방향으로 같은 가중치를 반복해서 사용한다.

역전파 과정에서 기울기가 여러 시점을 거치며 계속 곱해지기 때문에, 기울기가 점점 작아질 수 있다.

기울기가 너무 작아지면 앞쪽 시점의 정보가 제대로 학습되지 않는다.

즉, RNN은 긴 문맥이나 장기 의존성 Long-term Dependency을 학습하기 어렵다.

---

## 9. LSTM

LSTM은 Long Short-Term Memory의 약자로, RNN의 장기 의존성 문제를 완화하기 위해 만들어진 모델이다.

LSTM은 중요한 정보는 오래 유지하고, 불필요한 정보는 버릴 수 있도록 설계되었다.

RNN보다 긴 시퀀스 정보를 더 잘 기억할 수 있다.

---

## 10. LSTM의 핵심 아이디어

LSTM은 단순한 은닉 상태 외에 Cell State라는 정보를 사용한다.

Cell State는 중요한 정보를 장기적으로 전달하는 통로 역할을 한다.

LSTM은 여러 Gate를 이용해 어떤 정보를 기억하고, 어떤 정보를 잊을지 결정한다.

---

## 11. Cell State

Cell State는 LSTM에서 장기 기억을 담당하는 값이다.

일반 RNN은 은닉 상태 하나로 정보를 전달하지만, LSTM은 Cell State를 따로 두어 중요한 정보를 더 오래 유지할 수 있다.

```text id="0e9szr"
이전 Cell State → 현재 Cell State → 다음 Cell State
```

Cell State를 통해 앞쪽 시점의 정보가 뒤쪽 시점까지 더 잘 전달될 수 있다.

---

## 12. LSTM의 Gate 구조

LSTM은 세 가지 주요 Gate를 사용한다.

| Gate        | 역할                |
| ----------- | ----------------- |
| Forget Gate | 이전 정보 중 버릴 정보를 결정 |
| Input Gate  | 새롭게 저장할 정보를 결정    |
| Output Gate | 현재 시점의 출력 정보를 결정  |

Gate는 Sigmoid 함수를 사용하여 0과 1 사이의 값을 만든다.

값이 0에 가까우면 정보를 거의 통과시키지 않고, 1에 가까우면 정보를 많이 통과시킨다.

---

## 13. Forget Gate

Forget Gate는 이전 Cell State에서 어떤 정보를 버릴지 결정한다.

예를 들어 문장에서 더 이상 필요하지 않은 앞쪽 정보를 제거하는 역할을 할 수 있다.

```text id="p89stu"
이전 기억 중 무엇을 잊을 것인가?
```

Forget Gate를 통해 LSTM은 불필요한 정보를 계속 유지하지 않도록 조절한다.

---

## 14. Input Gate

Input Gate는 현재 입력 정보를 Cell State에 얼마나 반영할지 결정한다.

```text id="yjsqzb"
현재 입력 중 무엇을 새롭게 기억할 것인가?
```

Input Gate는 새로운 정보 중 중요한 것만 선택적으로 저장한다.

---

## 15. Output Gate

Output Gate는 현재 Cell State를 바탕으로 어떤 값을 출력할지 결정한다.

```text id="6cnjzu"
현재 시점에서 무엇을 출력할 것인가?
```

Output Gate를 통해 현재 시점의 은닉 상태가 만들어지고, 이 값은 다음 시점으로 전달된다.

---

## 16. RNN과 LSTM 비교

| 구분        | RNN          | LSTM                      |
| --------- | ------------ | ------------------------- |
| 구조        | 단순함          | 복잡함                       |
| 기억 방식     | Hidden State | Hidden State + Cell State |
| 장기 의존성 학습 | 어려움          | 상대적으로 강함                  |
| 기울기 소실 문제 | 발생하기 쉬움      | 완화 가능                     |
| 계산 비용     | 적음           | 상대적으로 큼                   |

---

## 17. GRU

GRU는 Gated Recurrent Unit의 약자로, LSTM을 조금 더 단순화한 구조이다.

GRU는 LSTM처럼 Gate를 사용하지만, Cell State를 따로 두지 않고 Hidden State만 사용한다.

### 특징

* LSTM보다 구조가 단순하다.
* 계산량이 상대적으로 적다.
* 장기 의존성 문제를 어느 정도 완화할 수 있다.
* 데이터나 문제에 따라 LSTM과 비슷한 성능을 낼 수 있다.

---

## 18. RNN 계열 모델의 한계

RNN, LSTM, GRU는 순차 데이터를 처리하는 데 유용하지만 다음과 같은 한계가 있다.

* 시퀀스를 순서대로 처리하므로 병렬 연산이 어렵다.
* 긴 문장을 처리할수록 계산 시간이 길어진다.
* 아주 긴 문맥을 완벽하게 기억하기 어렵다.
* 입력의 모든 위치 관계를 한 번에 파악하기 어렵다.

이러한 한계를 보완하기 위해 Attention과 Transformer 구조가 등장했다.

---

## 19. 정리

* RNN은 순서가 있는 데이터를 처리하기 위한 신경망이다.
* RNN은 이전 시점의 은닉 상태를 현재 시점 계산에 사용한다.
* Hidden State는 이전 시점까지의 정보를 담고 있는 값이다.
* RNN은 긴 시퀀스에서 기울기 소실 문제가 발생하기 쉽다.
* LSTM은 RNN의 장기 의존성 문제를 완화하기 위해 만들어졌다.
* LSTM은 Cell State와 Gate 구조를 사용한다.
* Forget Gate는 버릴 정보를 결정한다.
* Input Gate는 새롭게 저장할 정보를 결정한다.
* Output Gate는 현재 출력할 정보를 결정한다.
* GRU는 LSTM을 단순화한 구조이다.
* RNN 계열 모델의 한계를 보완하기 위해 Attention과 Transformer가 등장했다.
