Loss Function 개념 정리

1. Loss Function

Loss Function은 모델의 예측값과 실제값의 차이를 측정하는 함수이다.

모델은 학습 과정에서 손실 함수 값을 줄이는 방향으로 가중치와 편향을 업데이트한다.

즉, 손실 함수는 모델이 얼마나 틀렸는지를 숫자로 나타내는 기준이다.

---

2. Loss와 Cost

Loss와 Cost는 비슷하게 사용되지만, 엄밀히는 다음과 같이 구분할 수 있다.

용어| 의미
Loss| 하나의 데이터에 대한 예측 오차
Cost| 전체 데이터에 대한 평균 손실

실제로는 두 용어를 거의 비슷한 의미로 사용하는 경우가 많다.

---

3. 손실 함수가 필요한 이유

딥러닝 모델은 예측값을 만든 뒤, 실제값과 얼마나 차이가 나는지 계산해야 한다.

이 차이를 기준으로 모델은 다음 학습 방향을 결정한다.

- 예측이 많이 틀리면 손실값이 커진다.
- 예측이 정확하면 손실값이 작아진다.
- 학습의 목표는 손실값을 최소화하는 것이다.

---

4. 회귀 문제의 손실 함수

회귀 문제는 연속형 값을 예측하는 문제이다.

예를 들어 주택 가격, 매출액, 기온, 점수 등을 예측하는 경우가 회귀 문제에 해당한다.

---

4.1. MSE Mean Squared Error

MSE는 실제값과 예측값의 차이를 제곱한 뒤 평균을 구하는 손실 함수이다.

$$
MSE = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2
$$

- $y_i$: 실제값
- $\hat{y}_i$: 예측값
- $N$: 데이터 개수

특징

- 오차를 제곱하기 때문에 큰 오차에 더 큰 패널티를 준다.
- 회귀 문제에서 가장 많이 사용되는 손실 함수 중 하나이다.
- 이상치가 있으면 손실값이 크게 증가할 수 있다.

---

4.2. MAE Mean Absolute Error

MAE는 실제값과 예측값의 차이에 절댓값을 씌운 뒤 평균을 구하는 손실 함수이다.

$$
MAE = \frac{1}{N} \sum_{i=1}^{N} |y_i - \hat{y}_i|
$$

특징

- 오차의 절댓값을 사용한다.
- MSE보다 이상치의 영향을 상대적으로 덜 받는다.
- 오차를 직관적으로 해석하기 쉽다.

---

4.3. MSE와 MAE 비교

구분| MSE| MAE
계산 방식| 오차 제곱의 평균| 오차 절댓값의 평균
이상치 영향| 큼| 상대적으로 작음
특징| 큰 오차에 민감| 오차 크기를 직관적으로 해석 가능
사용 문제| 회귀| 회귀

---

5. 분류 문제의 손실 함수

분류 문제는 입력 데이터를 특정 클래스 중 하나로 분류하는 문제이다.

분류 문제에서는 모델의 출력 확률과 실제 클래스 사이의 차이를 측정하는 손실 함수를 사용한다.

---

5.1. Binary Cross Entropy

Binary Cross Entropy는 이진 분류에서 사용하는 손실 함수이다.

정답 클래스가 0 또는 1이고, 모델이 클래스 1에 속할 확률을 출력할 때 사용한다.

$$
BCE = - \frac{1}{N} \sum_{i=1}^{N} \left[y_i \log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)\right]
$$

- $y_i$: 실제 클래스
- $\hat{y}_i$: 모델이 예측한 클래스 1의 확률

특징

- 이진 분류 문제에 사용한다.
- 출력층 활성화 함수로 Sigmoid를 함께 사용하는 경우가 많다.
- 실제값과 예측 확률이 멀수록 손실값이 커진다.

사용 예시

문제 유형| 출력층 활성화 함수| 손실 함수
이진 분류| Sigmoid| Binary Cross Entropy

---

5.2. Cross Entropy Loss

Cross Entropy Loss는 다중 분류에서 사용하는 손실 함수이다.

모델이 각 클래스에 속할 확률을 예측하고, 실제 정답 클래스의 확률이 낮을수록 손실값이 커진다.

$$
CE = - \sum_{k=1}^{K} y_k \log(\hat{y}_k)
$$

- $K$: 클래스 개수
- $y_k$: 실제 클래스 여부
- $\hat{y}_k$: k번째 클래스에 대한 예측 확률

특징

- 다중 분류 문제에 사용한다.
- 출력층 활성화 함수로 Softmax를 함께 사용하는 경우가 많다.
- 정답 클래스에 높은 확률을 줄수록 손실값이 작아진다.

사용 예시

문제 유형| 출력층 활성화 함수| 손실 함수
다중 분류| Softmax| Cross Entropy Loss

---

6. 문제 유형별 손실 함수 선택

문제 유형| 예측 대상| 대표 손실 함수
회귀| 연속형 값| MSE, MAE
이진 분류| 0 또는 1| Binary Cross Entropy
다중 분류| 여러 클래스 중 하나| Cross Entropy Loss

---

7. 손실 함수와 활성화 함수의 관계

손실 함수는 출력층 활성화 함수와 함께 선택하는 경우가 많다.

문제 유형| 출력층 활성화 함수| 손실 함수
회귀| Linear 또는 없음| MSE, MAE
이진 분류| Sigmoid| Binary Cross Entropy
다중 분류| Softmax| Cross Entropy Loss

예를 들어 이진 분류에서는 Sigmoid를 사용해 클래스 1일 확률을 출력하고, Binary Cross Entropy로 실제값과의 차이를 계산한다.

다중 분류에서는 Softmax를 사용해 클래스별 확률을 출력하고, Cross Entropy Loss로 정답 클래스와의 차이를 계산한다.

---

8. 손실 함수와 학습 과정

딥러닝 모델의 학습 과정에서 손실 함수는 다음과 같이 사용된다.

1. 입력 데이터를 모델에 넣는다.
2. 모델이 예측값을 출력한다.
3. 손실 함수를 이용해 실제값과 예측값의 차이를 계산한다.
4. 역전파를 통해 각 가중치가 손실에 미친 영향을 계산한다.
5. 옵티마이저가 손실을 줄이는 방향으로 가중치를 업데이트한다.

즉, 손실 함수는 모델 학습의 기준이 되는 값이다.

---

9. 손실 함수 선택 시 주의할 점

- 문제 유형에 맞는 손실 함수를 선택해야 한다.
- 회귀 문제에는 분류용 손실 함수를 사용하지 않는다.
- 이진 분류와 다중 분류는 사용하는 손실 함수가 다르다.
- 손실값이 작다고 해서 항상 실제 성능 지표가 좋은 것은 아니다.
- 모델 평가에는 Accuracy, Precision, Recall, F1-score, RMSE 등 별도의 평가 지표를 함께 확인해야 한다.

---

10. 정리

- 손실 함수는 예측값과 실제값의 차이를 측정하는 함수이다.
- 모델은 손실 함수 값을 줄이는 방향으로 학습한다.
- 회귀 문제에서는 MSE, MAE를 자주 사용한다.
- 이진 분류에서는 Binary Cross Entropy를 사용한다.
- 다중 분류에서는 Cross Entropy Loss를 사용한다.
- 손실 함수는 출력층 활성화 함수와 함께 선택하는 경우가 많다.
- 손실 함수는 학습 기준이고, 평가 지표는 모델 성능을 해석하는 기준이다.
