Transfer Learning 개념 정리

1. Transfer Learning

Transfer Learning은 이미 큰 데이터셋으로 학습된 모델을 새로운 문제에 활용하는 방법이다.

한국어로는 전이학습이라고 한다.

처음부터 모델을 새로 학습하는 것이 아니라, 기존에 학습된 모델의 지식을 가져와 새로운 데이터와 문제에 맞게 조정한다.

---

2. Transfer Learning이 필요한 이유

딥러닝 모델은 일반적으로 많은 데이터와 연산 자원이 필요하다.

하지만 실제 프로젝트에서는 충분한 데이터를 확보하기 어렵거나, 모델을 처음부터 학습하기에는 시간이 오래 걸릴 수 있다.

Transfer Learning을 사용하면 이미 학습된 모델을 활용할 수 있기 때문에 적은 데이터로도 비교적 좋은 성능을 얻을 수 있다.

장점

- 학습 시간을 줄일 수 있다.
- 적은 데이터로도 성능을 높일 수 있다.
- 이미 학습된 특징을 활용할 수 있다.
- 초기 모델 성능을 빠르게 확보할 수 있다.

---

3. Pre-trained Model

Pre-trained Model은 대규모 데이터셋으로 미리 학습된 모델이다.

예를 들어 이미지 분야에서는 ImageNet 데이터셋으로 학습된 CNN 모델을 많이 사용하고, 자연어 처리 분야에서는 대규모 텍스트 데이터로 학습된 언어 모델을 많이 사용한다.

예시

분야| Pre-trained Model 예시
이미지| VGG, ResNet, EfficientNet, MobileNet
자연어 처리| BERT, GPT, RoBERTa, T5
이미지 생성| Stable Diffusion 계열 모델
음성| Wav2Vec, Whisper

---

4. Transfer Learning의 기본 아이디어

딥러닝 모델의 앞쪽 층은 일반적인 특징을 학습하는 경우가 많다.

예를 들어 이미지 모델의 앞쪽 층은 선, 모서리, 색상 변화 같은 기본 특징을 학습하고, 뒤쪽 층은 더 구체적인 객체 특징을 학습한다.

따라서 앞쪽 층에서 학습한 일반적인 특징은 다른 이미지 문제에도 재사용할 수 있다.

기존 대규모 데이터 학습
→ 일반적인 특징 학습
→ 새로운 데이터에 맞게 일부 층 수정
→ 새로운 문제에 적용

---

5. Feature Extraction

Feature Extraction은 Pre-trained Model을 특징 추출기로 사용하는 방법이다.

기존 모델의 대부분의 층은 그대로 두고, 마지막 출력층만 새로운 문제에 맞게 교체한다.

이때 기존 모델의 가중치는 고정하고, 새로 추가한 분류기 부분만 학습하는 경우가 많다.

특징

- 학습해야 할 파라미터 수가 적다.
- 학습 속도가 빠르다.
- 데이터가 적을 때 유용하다.
- 기존 모델이 학습한 특징을 그대로 활용한다.

---

6. Fine-tuning

Fine-tuning은 Pre-trained Model의 일부 또는 전체 가중치를 새로운 데이터에 맞게 조금 더 학습시키는 방법이다.

Feature Extraction보다 더 적극적으로 기존 모델을 조정한다.

특징

- 새로운 데이터에 더 잘 맞게 모델을 조정할 수 있다.
- 성능 향상을 기대할 수 있다.
- 학습 데이터가 너무 적으면 과대적합이 발생할 수 있다.
- 학습률을 작게 설정하는 경우가 많다.

---

7. Freezing

Freezing은 모델의 특정 층을 학습되지 않도록 고정하는 것이다.

Pre-trained Model의 앞쪽 층을 고정하고, 뒤쪽 층이나 새로 추가한 층만 학습하는 방식으로 자주 사용된다.

Frozen Layers: 기존 가중치 유지
Trainable Layers: 새로운 데이터로 학습

사용하는 이유

- 기존 모델이 학습한 일반적인 특징을 유지하기 위해
- 학습해야 할 파라미터 수를 줄이기 위해
- 과대적합을 줄이기 위해
- 학습 시간을 줄이기 위해

---

8. Feature Extraction과 Fine-tuning 비교

구분| Feature Extraction| Fine-tuning
기존 모델 가중치| 대부분 고정| 일부 또는 전체 학습
학습 속도| 빠름| 상대적으로 느림
필요한 데이터| 적어도 가능| 어느 정도 필요
성능 개선 가능성| 제한적일 수 있음| 더 높을 수 있음
과대적합 위험| 상대적으로 낮음| 상대적으로 높음

---

9. Transfer Learning의 일반적인 절차

Transfer Learning은 보통 다음 순서로 진행한다.

1. Pre-trained Model을 불러온다.
2. 기존 출력층을 제거하거나 교체한다.
3. 새로운 문제에 맞는 출력층을 추가한다.
4. 기존 층을 Freeze할지 결정한다.
5. 새로운 데이터로 모델을 학습한다.
6. 필요하면 일부 층을 Unfreeze하여 Fine-tuning한다.
7. 검증 데이터로 성능을 평가한다.

---

10. 이미지 분야의 Transfer Learning

이미지 분류에서는 ImageNet으로 학습된 CNN 모델을 많이 활용한다.

예를 들어 고양이와 강아지를 분류하는 모델을 만들 때, ResNet이나 EfficientNet처럼 이미 학습된 모델을 불러와 마지막 분류층만 바꿔 사용할 수 있다.

활용 예시

- 이미지 분류
- 객체 탐지
- 의료 영상 분석
- 얼굴 인식
- 불량품 검출

---

11. 자연어 처리 분야의 Transfer Learning

자연어 처리에서는 대규모 텍스트로 학습된 언어 모델을 활용한다.

BERT, GPT 같은 모델은 문장 구조와 단어 의미를 이미 학습하고 있기 때문에, 특정 작업에 맞게 추가 학습하여 사용할 수 있다.

활용 예시

- 감성 분석
- 문장 분류
- 질의응답
- 문서 요약
- 개체명 인식
- 챗봇

---

12. Downstream Task

Downstream Task는 Pre-trained Model을 활용하여 실제로 해결하려는 구체적인 작업을 의미한다.

예를 들어 BERT를 미리 학습된 언어 모델이라고 할 때, 감성 분석이나 문장 분류는 Downstream Task에 해당한다.

Pre-trained Model| Downstream Task 예시
ResNet| 이미지 분류
BERT| 감성 분석, 문장 분류
GPT| 텍스트 생성, 질의응답
Whisper| 음성 인식

---

13. Transfer Learning 사용 시 주의할 점

Transfer Learning이 항상 좋은 결과를 보장하는 것은 아니다.

기존 모델이 학습한 데이터와 새로운 데이터의 특성이 너무 다르면 성능이 좋지 않을 수 있다.

주의할 점

- 기존 데이터와 새로운 데이터의 도메인이 너무 다르면 효과가 줄어들 수 있다.
- Fine-tuning 시 학습률을 너무 크게 설정하면 기존 지식이 손상될 수 있다.
- 데이터가 너무 적으면 과대적합이 발생할 수 있다.
- 새로운 문제에 맞게 출력층 구조를 수정해야 한다.
- 검증 데이터로 실제 성능을 반드시 확인해야 한다.

---

구분| From Scratch| Transfer Learning

초기 성능| 낮을 수 있음| 비교적 높음
사용 상황| 데이터가 충분할 때| 데이터가 적거나 빠른 실험이 필요할 때

---

15. Transfer Learning의 한계

Transfer Learning에도 한계가 있다.

- 기존 모델과 새로운 문제의 도메인이 다르면 효과가 낮을 수 있다.
- Pre-trained Model의 구조에 영향을 받는다.
- 모델 크기가 클 경우 추론 비용이 높을 수 있다.
- 기존 모델이 가진 편향이 새로운 문제에도 영향을 줄 수 있다.
- 특정 문제에서는 처음부터 학습한 모델이 더 적합할 수 있다.

---

16. 정리

- Transfer Learning은 이미 학습된 모델을 새로운 문제에 활용하는 방법이다.
- Pre-trained Model은 대규모 데이터로 미리 학습된 모델이다.
- Feature Extraction은 기존 모델을 특징 추출기로 사용하고 새 출력층만 학습하는 방식이다.
- Fine-tuning은 기존 모델의 일부 또는 전체 가중치를 새로운 데이터에 맞게 추가 학습하는 방식이다.
- Freezing은 특정 층의 가중치가 업데이트되지 않도록 고정하는 것이다.
- Transfer Learning은 적은 데이터와 짧은 시간으로 좋은 성능을 얻는 데 유용하다.
- 이미지, 자연어 처리, 음성 등 다양한 분야에서 사용된다.
- 기존 모델과 새로운 데이터의 도메인이 다르면 효과가 떨어질 수 있다.
