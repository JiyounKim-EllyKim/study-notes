# Sentiment Analysis 개념 정리

## 1. Sentiment Analysis

Sentiment Analysis는 텍스트에 담긴 감정이나 의견을 분석하는 NLP 작업이다.

한국어로는 감성 분석이라고 한다.

리뷰, 댓글, 게시글, 고객 문의 같은 텍스트를 분석하여 긍정, 부정, 중립 등의 감정을 분류한다.

---

## 2. Sentiment Analysis가 필요한 이유

텍스트 데이터에는 사용자의 의견, 만족도, 불만, 선호도 등이 담겨 있다.

감성 분석을 사용하면 많은 양의 텍스트를 직접 하나씩 읽지 않아도, 전체적인 반응과 감정 흐름을 파악할 수 있다.

### 활용 예시

* 상품 리뷰 긍정/부정 분석
* 고객 문의 불만 탐지
* SNS 반응 분석
* 브랜드 평판 분석
* 영화나 콘텐츠 리뷰 분석
* 서비스 개선 포인트 파악

---

## 3. Sentiment Analysis의 기본 흐름

감성 분석은 일반적인 텍스트 분류와 비슷한 흐름으로 진행된다.

```text id="hvk5f2"
Raw Text
→ Text Preprocessing
→ Tokenization
→ Vectorization / Embedding
→ Sentiment Classification Model
→ Sentiment Prediction
```

예측 결과는 보통 긍정, 부정, 중립 같은 감정 라벨로 나온다.

---

## 4. 감성 분석의 유형

감성 분석은 분류 기준에 따라 여러 유형으로 나눌 수 있다.

| 유형                                   | 설명                    | 예시                       |
| ------------------------------------ | --------------------- | ------------------------ |
| Binary Sentiment Classification      | 긍정/부정으로 분류            | 긍정 리뷰, 부정 리뷰             |
| Multi-class Sentiment Classification | 긍정/중립/부정 등 여러 감정으로 분류 | 긍정, 중립, 부정               |
| Fine-grained Sentiment Analysis      | 감정을 더 세밀하게 분류         | 매우 긍정, 긍정, 중립, 부정, 매우 부정 |
| Aspect-based Sentiment Analysis      | 특정 속성별 감정 분석          | 배송은 긍정, 가격은 부정           |

---

## 5. Binary Sentiment Classification

Binary Sentiment Classification은 텍스트를 긍정 또는 부정으로 분류하는 감성 분석이다.

```text id="bphk6h"
이 제품 정말 좋아요 → 긍정
다시는 안 살 것 같아요 → 부정
```

가장 기본적인 감성 분석 형태이다.

---

## 6. Multi-class Sentiment Classification

Multi-class Sentiment Classification은 감정을 여러 클래스로 나누어 분류하는 방식이다.

예를 들어 긍정, 중립, 부정으로 나눌 수 있다.

```text id="jsby0j"
배송이 빨라서 좋았어요 → 긍정
그냥 평범했어요 → 중립
포장이 너무 별로였어요 → 부정
```

중립 라벨이 포함되면 애매한 표현을 더 자연스럽게 분류할 수 있다.

---

## 7. Fine-grained Sentiment Analysis

Fine-grained Sentiment Analysis는 감정을 더 세밀한 단계로 나누는 방식이다.

예를 들어 별점 리뷰를 감성 라벨로 변환할 수 있다.

| 별점 | 감성    |
| -: | ----- |
| 5점 | 매우 긍정 |
| 4점 | 긍정    |
| 3점 | 중립    |
| 2점 | 부정    |
| 1점 | 매우 부정 |

세밀한 감정 단계를 다룰 수 있지만, 라벨 기준이 모호해질 수 있다.

---

## 8. Aspect-based Sentiment Analysis

Aspect-based Sentiment Analysis는 문장 전체의 감정이 아니라, 특정 속성 Aspect에 대한 감정을 분석하는 방법이다.

예를 들어 다음 문장을 보자.

```text id="ck4gns"
배송은 빨랐지만 포장은 별로였어요.
```

이 문장의 전체 감정은 애매하지만, 속성별로 보면 다르게 해석할 수 있다.

| Aspect | Sentiment |
| ------ | --------- |
| 배송     | 긍정        |
| 포장     | 부정        |

Aspect-based Sentiment Analysis는 상품 리뷰나 고객 피드백 분석에서 유용하다.

---

## 9. 감성 분석 데이터

감성 분석에는 텍스트와 감성 라벨이 필요하다.

| Text           | Label |
| -------------- | ----- |
| 제품이 정말 마음에 들어요 | 긍정    |
| 배송이 너무 늦었어요    | 부정    |
| 그냥 무난했어요       | 중립    |

라벨 기준이 명확해야 모델이 일관된 패턴을 학습할 수 있다.

---

## 10. 감성 분석에서 중요한 표현

감성 분석에서는 단어 자체뿐만 아니라 문맥과 표현 방식도 중요하다.

### 중요한 표현

* 긍정어: 좋다, 만족, 추천, 훌륭하다
* 부정어: 별로, 실망, 불만, 최악
* 부정 표현: 안, 못, 아니다
* 강조 표현: 너무, 진짜, 완전, 매우
* 이모티콘: ㅋㅋ, ㅠㅠ, 😊, 😡
* 반어적 표현: 참 잘도 하겠다

감성 표현은 도메인과 사용자층에 따라 달라질 수 있다.

---

## 11. 부정어 처리

감성 분석에서 부정어는 매우 중요하다.

부정어를 제거하면 문장의 의미가 완전히 바뀔 수 있다.

```text id="c5xrnc"
맛있다 → 긍정
안 맛있다 → 부정
```

불용어 제거를 할 때 `안`, `못`, `아니다`, `별로` 같은 단어를 제거하지 않도록 주의해야 한다.

---

## 12. 강조 표현 처리

감성 분석에서는 강조 표현도 중요하다.

```text id="zshnvp"
좋아요 → 긍정
진짜 좋아요 → 더 강한 긍정
너무 별로예요 → 더 강한 부정
```

`진짜`, `완전`, `너무`, `매우` 같은 표현은 감정의 강도를 나타낼 수 있다.

따라서 무조건 제거하기보다 분석 목적에 맞게 처리해야 한다.

---

## 13. 이모티콘과 이모지 처리

리뷰나 댓글 데이터에서는 이모티콘과 이모지가 감정을 나타내는 중요한 정보가 될 수 있다.

```text id="t0dsxq"
좋아요 ㅋㅋ → 긍정 가능성
별로예요 ㅠㅠ → 부정 가능성
최고예요 😊 → 긍정 가능성
화나요 😡 → 부정 가능성
```

감성 분석에서는 이모티콘을 제거하지 않고 별도 토큰으로 변환하거나, 감성 사전에 반영할 수 있다.

---

## 14. 감성 분석 접근 방법

감성 분석은 크게 규칙 기반 방법, 머신러닝 기반 방법, 딥러닝 기반 방법으로 나눌 수 있다.

| 방법                         | 설명                         |
| -------------------------- | -------------------------- |
| Lexicon-based Approach     | 감성 사전을 이용해 점수 계산           |
| Machine Learning Approach  | TF-IDF 등 Feature로 분류 모델 학습 |
| Deep Learning Approach     | Embedding과 신경망으로 문맥 학습     |
| Transformer-based Approach | 사전학습 언어 모델을 Fine-tuning    |

---

## 15. Lexicon-based Approach

Lexicon-based Approach는 감성 사전을 이용해 문장의 감성 점수를 계산하는 방법이다.

감성 사전에는 단어별로 긍정 또는 부정 점수가 들어 있다.

```text id="my9fai"
좋다: +1
훌륭하다: +2
별로: -1
최악: -2
```

문장에 포함된 단어의 감성 점수를 더해 최종 감성을 판단할 수 있다.

### 장점

* 학습 데이터가 없어도 사용할 수 있다.
* 결과를 해석하기 쉽다.
* 간단한 분석에 빠르게 적용할 수 있다.

### 한계

* 문맥을 반영하기 어렵다.
* 신조어, 은어, 반어법에 약하다.
* 도메인별 감성 차이를 반영하기 어렵다.
* 감성 사전의 품질에 크게 의존한다.

---

## 16. Machine Learning 기반 감성 분석

Machine Learning 기반 감성 분석은 텍스트를 숫자 Feature로 변환한 뒤 분류 모델을 학습하는 방식이다.

```text id="bzy6y0"
Text
→ TF-IDF
→ Logistic Regression / SVM / Naive Bayes
→ Sentiment Prediction
```

대표적인 모델은 다음과 같다.

* Logistic Regression
* Naive Bayes
* SVM
* Random Forest
* Gradient Boosting

전통적인 감성 분석에서는 TF-IDF와 선형 모델을 baseline으로 자주 사용한다.

---

## 17. Deep Learning 기반 감성 분석

Deep Learning 기반 감성 분석은 단어 Embedding과 신경망을 이용해 문장의 의미와 감정을 학습한다.

대표적인 모델은 다음과 같다.

| 모델          | 특징                  |
| ----------- | ------------------- |
| CNN         | 특정 단어 조합이나 표현 패턴 포착 |
| RNN         | 문장 순서 정보 반영         |
| LSTM        | 긴 문맥 정보를 RNN보다 잘 유지 |
| Transformer | Attention 기반 문맥 이해  |

딥러닝 모델은 문맥을 더 잘 반영할 수 있지만, 데이터와 연산 자원이 더 많이 필요할 수 있다.

---

## 18. Transformer 기반 감성 분석

Transformer 기반 감성 분석은 BERT 같은 사전학습 언어 모델을 감성 분석 데이터에 맞게 Fine-tuning하는 방식이다.

```text id="lyuiow"
Review Text
→ Tokenizer
→ Pre-trained Transformer
→ Classification Head
→ Sentiment Label
```

### 특징

* 문맥을 잘 반영할 수 있다.
* 적은 데이터에서도 좋은 성능을 기대할 수 있다.
* 한국어 모델을 사용할 경우 한국어 문맥 이해에 유리하다.
* 모델 크기가 커서 학습과 추론 비용이 높을 수 있다.

---

## 19. 감성 분석 전처리

감성 분석에서는 일반적인 텍스트 전처리보다 의미 보존이 더 중요하다.

특히 감정을 나타내는 표현을 함부로 제거하면 안 된다.

### 주의할 표현

* 부정어
* 감탄사
* 이모지
* 이모티콘
* 반복 문자
* 강조 부사
* 구두점
* 별점이나 숫자

예를 들어 `좋아요!!!`와 `좋아요`는 모두 긍정이지만, 감정 강도는 다를 수 있다.

---

## 20. 감성 분석 평가 지표

감성 분석은 분류 문제이므로 Classification 평가 지표를 사용한다.

| 지표               | 설명                          |
| ---------------- | --------------------------- |
| Accuracy         | 전체 데이터 중 맞게 예측한 비율          |
| Precision        | 특정 감정으로 예측한 것 중 실제 해당 감정 비율 |
| Recall           | 실제 특정 감정 중 모델이 맞게 찾은 비율     |
| F1-score         | Precision과 Recall의 조화 평균    |
| Confusion Matrix | 감정 클래스별 오분류 확인              |

클래스 불균형이 있는 경우 Accuracy만으로 평가하면 안 된다.

---

## 21. 클래스 불균형 문제

감성 분석 데이터는 긍정 리뷰가 부정 리뷰보다 훨씬 많거나, 중립 데이터가 적은 경우가 있다.

이런 경우 모델이 많은 클래스만 잘 예측해도 Accuracy가 높게 나올 수 있다.

### 해결 방법

* 데이터 추가 수집
* Oversampling
* Undersampling
* Class Weight 조정
* Threshold 조정
* F1-score, Recall 등 적절한 지표 사용

---

## 22. Error Analysis

감성 분석에서는 모델이 틀린 문장을 직접 확인하는 것이 중요하다.

### 확인할 점

* 부정어를 제대로 처리했는가?
* 반어적 표현을 오해했는가?
* 중립과 긍정을 헷갈리는가?
* 별점과 리뷰 내용이 일치하지 않는가?
* 신조어, 줄임말, 이모티콘을 처리하지 못했는가?
* 특정 도메인 용어를 잘못 해석했는가?

Error Analysis를 통해 전처리 방식, 라벨 기준, 모델 개선 방향을 정할 수 있다.

---

## 23. 감성 분석의 어려움

감성 분석은 단순히 긍정어와 부정어를 세는 것만으로 해결하기 어렵다.

### 어려운 예시

```text id="r2rxpp"
생각보다 괜찮았어요.
별로 기대 안 했는데 좋았어요.
참 빨리도 왔네요.
디자인은 예쁜데 착용감은 별로예요.
```

감정은 문맥, 기대치, 반어법, 속성별 평가에 따라 달라질 수 있다.

---

## 24. 감성 분석 사용 시 주의할 점

* 부정어를 불용어로 제거하지 않도록 주의해야 한다.
* 이모티콘과 반복 표현이 감정 정보일 수 있다.
* 별점과 리뷰 텍스트가 항상 일치하는 것은 아니다.
* 긍정/부정 기준이 도메인마다 다를 수 있다.
* 클래스 불균형을 확인해야 한다.
* 모델이 틀린 문장을 직접 확인해야 한다.
* 감성 분석 결과를 절대적인 사실이 아니라 해석의 보조 지표로 활용해야 한다.

---

## 25. 정리

* Sentiment Analysis는 텍스트에 담긴 감정이나 의견을 분석하는 NLP 작업이다.
* 감성 분석은 리뷰, 댓글, SNS, 고객 문의 분석 등에 활용된다.
* 감성 분석은 긍정/부정 이진 분류, 긍정/중립/부정 다중 분류, 속성 기반 분석으로 나눌 수 있다.
* Aspect-based Sentiment Analysis는 특정 속성별 감정을 분석한다.
* 감성 분석에서는 부정어, 강조 표현, 이모티콘, 반복 문자를 주의해서 처리해야 한다.
* Lexicon-based Approach는 감성 사전을 이용해 감성 점수를 계산한다.
* Machine Learning 기반 방법은 TF-IDF와 분류 모델을 함께 사용할 수 있다.
* Transformer 기반 방법은 문맥을 더 잘 반영할 수 있다.
* 클래스 불균형이 있으면 Accuracy만으로 평가하면 안 된다.
* Error Analysis를 통해 모델이 어떤 표현을 잘못 해석하는지 확인해야 한다.
