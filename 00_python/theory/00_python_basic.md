Python Basic 개념 정리

1. Python

Python은 문법이 간결하고 가독성이 높은 범용 프로그래밍 언어이다.

데이터 분석, 머신러닝, 딥러닝, 웹 개발, 자동화 등 다양한 분야에서 사용된다.

특징

- 문법이 간결하고 읽기 쉽다.
- 동적 타입 언어이다.
- 인터프리터를 통해 실행할 수 있다.
- 다양한 라이브러리와 프레임워크를 제공한다.
- 객체 지향 프로그래밍을 지원한다.

---

2. 기본 문법

Python은 들여쓰기를 사용하여 코드 블록을 구분한다.

if True:
    print("Hello, Python!")

다른 언어에서 사용하는 중괄호 "{}" 대신 들여쓰기로 코드의 구조를 표현한다.

일반적으로 공백 4칸을 사용한다.

주의할 점

- 같은 코드 블록에서는 들여쓰기를 일관되게 사용해야 한다.
- 들여쓰기가 잘못되면 "IndentationError"가 발생할 수 있다.
- Python은 대소문자를 구분한다.

---

3. 변수 Variable

변수는 데이터를 참조하기 위해 사용하는 이름이다.

Python에서는 별도의 자료형 선언 없이 변수를 생성할 수 있다.

name = "Python"
age = 25
score = 95.5

변수에는 문자열, 정수, 실수 등 다양한 객체를 할당할 수 있다.

변수 명명 규칙

- 영문자, 숫자, 밑줄 "_"을 사용할 수 있다.
- 숫자로 시작할 수 없다.
- Python 예약어를 사용할 수 없다.
- 대소문자를 구분한다.

user_name = "Kim"
total_score = 100

Python에서는 변수명에 "snake_case"를 사용하는 것이 일반적이다.

---

4. Dynamic Typing

Python은 동적 타입 언어이다.

변수의 자료형을 미리 선언할 필요가 없으며, 실행 중 다른 자료형의 객체를 할당할 수 있다.

x = 10
x = "Hello"

첫 번째 코드에서 "x"는 정수 객체를 참조하고, 두 번째 코드에서는 문자열 객체를 참조한다.

Python에서는 변수 자체보다 객체가 자료형을 가진다고 이해하는 것이 정확하다.

---

5. 기본 자료형

Python의 대표적인 기본 자료형은 다음과 같다.

자료형| 설명| 예시
"int"| 정수| "10", "-5"
"float"| 실수| "3.14", "0.5"
"str"| 문자열| ""Python""
"bool"| 논리형| "True", "False"
"NoneType"| 값이 없음을 나타내는 타입| "None"

a = 10
b = 3.14
c = "Python"
d = True
e = None

"type()" 함수를 사용하면 객체의 자료형을 확인할 수 있다.

print(type(a))  # <class 'int'>
print(type(c))  # <class 'str'>

---

6. 숫자형 Number

숫자형은 주로 정수 "int"와 실수 "float"를 사용한다.

a = 10
b = 3.5

Python은 일반적인 정수 연산에서 고정된 비트 크기의 정수형을 사용하지 않으므로 매우 큰 정수도 표현할 수 있다. 다만 실제 사용 가능한 메모리에는 제한이 있다.

실수는 부동소수점 방식으로 표현하기 때문에 일부 소수는 정확하게 저장되지 않을 수 있다.

print(0.1 + 0.2)
# 0.30000000000000004

따라서 실수 비교에서는 부동소수점 오차를 고려해야 한다.

---

7. 문자열 String

문자열은 문자들의 순서 있는 시퀀스이다.

작은따옴표 또는 큰따옴표를 사용해 생성할 수 있다.

a = 'Python'
b = "Data Analysis"

여러 줄의 문자열은 삼중 따옴표로 표현할 수 있다.

text = """Hello
Python
World"""

문자열은 변경 불가능한 Immutable 객체이다.

즉, 생성된 문자열의 특정 문자를 직접 수정할 수 없다.

---

8. 문자열 인덱싱과 슬라이싱

문자열은 인덱스를 통해 특정 문자에 접근할 수 있다.

text = "Python"

print(text[0])   # P
print(text[-1])  # n

인덱스는 0부터 시작하며, 음수 인덱스는 뒤에서부터 접근한다.

Slicing

Slicing은 문자열의 특정 범위를 추출하는 방법이다.

text = "Python"

print(text[0:3])  # Pyt
print(text[2:])   # thon
print(text[:4])   # Pyth
print(text[::-1]) # nohtyP

기본 형식은 다음과 같다.

sequence[start:stop:step]

"stop" 위치의 문자는 포함되지 않는다.

---

9. 문자열 포매팅

문자열 포매팅은 문자열 안에 변수나 표현식의 값을 삽입하는 방법이다.

f-string

Python에서는 f-string을 자주 사용한다.

name = "Python"
score = 95

print(f"{name} 점수는 {score}점입니다.")

출력 결과:

Python 점수는 95점입니다.

f-string에서는 중괄호 안에 표현식을 넣을 수 있다.

a = 10
b = 20

print(f"합계: {a + b}")

숫자의 출력 형식도 지정할 수 있다.

pi = 3.141592

print(f"{pi:.2f}")  # 3.14

---

10. 산술 연산자

산술 연산자는 숫자 계산에 사용하는 연산자이다.

연산자| 설명| 예시| 결과
"+"| 덧셈| "10 + 3"| 13
"-"| 뺄셈| "10 - 3"| 7
"*"| 곱셈| "10 * 3"| 30
"/"| 나눗셈| "10 / 3"| 3.333...
"//"| 몫을 내림| "10 // 3"| 3
"%"| 나머지| "10 % 3"| 1
"**"| 거듭제곱| "10 ** 2"| 100

주의할 점

"/"는 일반적으로 "float" 결과를 반환한다.

"//"는 결과를 음의 무한대 방향으로 내림한다.

print(-10 // 3)  # -4

---

11. 비교 연산자

비교 연산자는 두 값을 비교하여 "True" 또는 "False"를 반환한다.

연산자| 설명
"=="| 두 값이 같은가
"!="| 두 값이 다른가
">"| 왼쪽 값이 더 큰가
"<"| 왼쪽 값이 더 작은가
">="| 왼쪽 값이 크거나 같은가
"<="| 왼쪽 값이 작거나 같은가

a = 10
b = 5

print(a > b)   # True
print(a == b)  # False

"=="와 "is"의 차이

- "==": 두 객체의 값이 같은지 비교
- "is": 두 변수가 동일한 객체를 참조하는지 비교

"None"과 비교할 때는 일반적으로 "is None" 또는 "is not None"을 사용한다.

---

12. 논리 연산자

논리 연산자는 조건을 결합하거나 부정하는 데 사용한다.

연산자| 설명
"and"| 두 조건이 모두 참인지 확인
"or"| 두 조건 중 하나 이상이 참인지 확인
"not"| 논리값을 반대로 변환

age = 25
score = 90

print(age >= 20 and score >= 80)  # True
print(age < 20 or score >= 80)    # True
print(not age >= 20)              # False

"and", "or"는 단락 평가 Short-circuit Evaluation을 수행한다.

조건에 따라 오른쪽 표현식이 실행되지 않을 수 있다.

---

13. 할당 연산자

할당 연산자는 변수에 값을 할당하거나 기존 값을 갱신하는 데 사용한다.

연산자| 설명
"="| 값 할당
"+="| 더한 뒤 할당
"-="| 뺀 뒤 할당
"*="| 곱한 뒤 할당
"/="| 나눈 뒤 할당
"//="| 몫을 구한 뒤 할당
"%="| 나머지를 구한 뒤 할당

x = 10

x += 5
print(x)  # 15

x *= 2
print(x)  # 30

---

14. 형 변환 Type Casting

형 변환은 데이터의 자료형을 다른 자료형으로 변환하는 과정이다.

대표적으로 다음 함수를 사용한다.

함수| 설명
"int()"| 정수로 변환
"float()"| 실수로 변환
"str()"| 문자열로 변환
"bool()"| 논리값으로 변환

a = "100"
b = int(a)

print(b + 10)  # 110

실수를 정수로 변환하면 소수점 아래 부분이 0 방향으로 버려진다.

print(int(3.9))   # 3
print(int(-3.9))  # -3

모든 값이 원하는 자료형으로 변환되는 것은 아니다.

int("Python")  # ValueError 발생

---

15. Truthy와 Falsy

Python에서는 "True", "False"뿐만 아니라 다른 객체도 조건문에서 참 또는 거짓으로 평가될 수 있다.

대표적인 Falsy 값은 다음과 같다.

- "False"
- "None"
- "0", "0.0"
- """" (빈 문자열)
- "[]" (빈 리스트)
- "{}" (빈 딕셔너리)
- "()" (빈 튜플)
- "set()" (빈 집합)

print(bool(0))        # False
print(bool(""))       # False
print(bool("Python")) # True
print(bool(10))       # True

참으로 평가되는 값을 Truthy, 거짓으로 평가되는 값을 Falsy라고 한다.

16. 입력과 출력

print()

"print()"는 데이터를 화면에 출력하는 함수이다.

print("Hello, Python!")

여러 값을 동시에 출력할 수도 있다.

name = "Python"
version = 3

print(name, version)

"sep"과 "end" 매개변수로 출력 형식을 조절할 수 있다.

print("A", "B", "C", sep="-")
# A-B-C

print("Hello", end=" ")
print("World")
# Hello World

input()

"input()"은 사용자에게 입력을 받는 함수이다.

name = input("이름을 입력하세요: ")
print(f"안녕하세요, {name}님!")

"input()"의 반환값은 문자열 "str"이다.

숫자 계산이 필요하면 형 변환을 해야 한다.

age = int(input("나이를 입력하세요: "))

17. 주석 Comment

주석은 코드의 설명을 작성하기 위한 문장으로, 실행되지 않는다.

Python에서는 "#"을 사용한다.

# 두 숫자의 합을 계산
a = 10
b = 20

result = a + b  # 합계 저장

주석은 코드의 목적이나 중요한 판단 근거를 설명할 때 유용하다.

단순히 코드 내용을 반복하기보다, 왜 해당 코드를 작성했는지 설명하는 것이 좋다.

18. 자주 사용하는 내장 함수

Python은 별도의 라이브러리 없이 사용할 수 있는 여러 내장 함수를 제공한다.

함수| 설명
"print()"| 출력
"input()"| 사용자 입력
"type()"| 자료형 확인
"len()"| 길이 확인
"int()"| 정수 변환
"float()"| 실수 변환
"str()"| 문자열 변환
"abs()"| 절댓값
"round()"| 반올림
"min()"| 최솟값
"max()"| 최댓값
"sum()"| 합계

numbers = [10, 20, 30]

print(len(numbers))  # 3
print(sum(numbers))  # 60
print(max(numbers))  # 30
print(min(numbers))  # 10

"round()"는 정확히 중간에 있는 값을 처리할 때 가장 가까운 짝수를 선택하는 반올림 규칙을 사용한다. 부동소수점 표현 오차도 결과에 영향을 줄 수 있다.

---

19. Python 코드 작성 시 주의할 점

- 들여쓰기는 공백 4칸을 기준으로 일관되게 작성한다.
- 변수명은 의미를 알 수 있도록 작성한다.
- 변수명에는 일반적으로 "snake_case"를 사용한다.
- 문자열과 숫자형을 혼동하지 않는다.
- "input()"은 문자열을 반환한다는 점을 기억한다.
- "/"와 "//"의 차이를 구분한다.
- 실수 연산에서는 부동소수점 오차를 고려한다.
- 값 비교에는 "==", 객체 동일성 비교에는 "is"를 사용한다.
- 불필요한 형 변환을 반복하지 않는다.
- 오류가 발생하면 예외 메시지와 발생 위치를 확인한다.

20. 정리

- Python은 데이터 분석, 머신러닝, 웹 개발 등 다양한 분야에서 사용하는 범용 프로그래밍 언어이다.
- Python은 들여쓰기를 사용하여 코드 블록을 구분한다.
- 변수는 객체를 참조하는 이름이며, Python은 동적 타입 언어이다.
- 기본 자료형에는 "int", "float", "str", "bool", "NoneType" 등이 있다.
- 문자열은 Immutable 객체이며, 인덱싱과 슬라이싱을 지원한다.
- f-string을 사용하면 문자열에 변수와 표현식을 쉽게 삽입할 수 있다.
- 산술 연산자로 "+", "-", "*", "/", "//", "%", "**" 등을 사용한다.
- 비교 연산자는 두 값을 비교하여 논리값을 반환한다.
- "and", "or", "not"을 이용해 논리 연산을 수행할 수 있다.
- "int()", "float()", "str()", "bool()" 등을 이용해 형 변환할 수 있다.
- "print()"는 출력, "input()"은 사용자 입력에 사용한다.
- Python의 내장 함수를 활용하면 기본적인 데이터 처리를 간단하게 수행할 수 있다.
