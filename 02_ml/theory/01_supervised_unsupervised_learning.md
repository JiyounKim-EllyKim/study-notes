Supervised Learning과 Unsupervised Learning 개념 정리

1. 학습 방식에 따른 머신러닝 분류

머신러닝은 학습 방식에 따라 크게 지도학습과 비지도학습으로 나눌 수 있다.

학습 방식| 설명| 대표 문제
지도학습 Supervised Learning| 정답이 있는 데이터로 학습| 회귀, 분류
비지도학습 Unsupervised Learning| 정답 없이 데이터의 구조를 학습| 군집화, 차원 축소

지도학습은 입력 데이터와 정답을 함께 사용하고, 비지도학습은 정답 없이 입력 데이터만 사용한다.

---

2. Supervised Learning 지도학습

지도학습은 입력 데이터와 정답 데이터가 함께 주어진 상태에서 모델을 학습하는 방법이다.

모델은 입력값과 정답 사이의 관계를 학습하고, 새로운 입력값이 들어왔을 때 정답을 예측한다.

입력 데이터 X + 정답 y → 모델 학습
새로운 입력 데이터 X → 예측값

---

3. 지도학습의 구성 요소

지도학습은 주로 다음 요소로 구성된다.

구성 요소| 설명
Feature| 예측에 사용하는 입력 변수
Label| 모델이 예측해야 하는 정답값
Model| Feature와 Label 사이의 관계를 학습하는 알고리즘
Prediction| 학습된 모델이 새로운 데이터에 대해 출력하는 예측값

예를 들어 고객 이탈 예측 문제에서는 고객의 이용 기간, 결제 금액, 접속 횟수 등이 Feature가 되고, 이탈 여부가 Label이 된다.

---

4. 지도학습의 주요 문제 유형

지도학습은 크게 회귀와 분류로 나눌 수 있다.

문제 유형| 설명| 예시
회귀 Regression| 연속형 숫자 값을 예측| 매출 예측, 집값 예측
분류 Classification| 정해진 클래스 중 하나를 예측| 스팸 여부, 이탈 여부

---

5. Regression 회귀

회귀는 연속형 값을 예측하는 지도학습 문제이다.

예측값이 숫자 형태이며, 값의 크기 자체가 의미를 가진다.

예시

- 주택 가격 예측
- 월 매출 예측
- 기온 예측
- 시험 점수 예측
- 고객 구매 금액 예측

대표 알고리즘

- Linear Regression
- Ridge Regression
- Lasso Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

---

6. Classification 분류

분류는 데이터를 정해진 클래스 중 하나로 나누는 지도학습 문제이다.

예측값은 숫자 자체의 크기보다 어느 클래스에 속하는지가 중요하다.

예시

- 스팸 메일 여부 분류
- 고객 이탈 여부 예측
- 질병 여부 예측
- 합격 / 불합격 예측
- 상품 카테고리 분류

대표 알고리즘

- Logistic Regression
- K-Nearest Neighbors
- Decision Tree Classifier
- Random Forest Classifier
- Support Vector Machine
- Gradient Boosting Classifier

---

7. 지도학습의 장점과 한계

장점

- 정답 데이터가 있기 때문에 모델 성능을 명확하게 평가할 수 있다.
- 예측 문제에 직접적으로 활용하기 좋다.
- 회귀와 분류처럼 실무에서 자주 사용되는 문제를 해결할 수 있다.

한계

- 정답 Label이 필요하다.
- Label을 수집하거나 만드는 데 비용이 많이 들 수 있다.
- 학습 데이터와 다른 패턴의 새로운 데이터에는 성능이 떨어질 수 있다.
- 과대적합이 발생할 수 있다.

---

8. Unsupervised Learning 비지도학습

비지도학습은 정답 데이터 없이 입력 데이터만으로 패턴이나 구조를 찾는 방법이다.

모델은 데이터 간의 유사성, 분포, 숨겨진 구조를 학습한다.

입력 데이터 X → 데이터의 구조나 패턴 학습

비지도학습은 정답을 예측하기보다 데이터를 이해하고 탐색하는 데 많이 사용된다.

---

9. 비지도학습의 주요 문제 유형

비지도학습의 대표적인 문제 유형은 군집화와 차원 축소이다.

문제 유형| 설명| 예시
군집화 Clustering| 비슷한 데이터끼리 그룹화| 고객 세분화
차원 축소 Dimensionality Reduction| 데이터의 차원을 줄임| PCA, 시각화
이상치 탐지 Anomaly Detection| 일반적이지 않은 데이터 탐지| 이상 거래 탐지

---

10. Clustering 군집화

군집화는 비슷한 특성을 가진 데이터끼리 그룹으로 묶는 방법이다.

정답 Label이 없기 때문에 모델이 데이터 간의 거리나 유사성을 기준으로 그룹을 찾는다.

예시

- 고객 세분화
- 유사 상품 그룹화
- 뉴스 기사 주제 묶기
- 사용자 행동 패턴 분석

대표 알고리즘

- K-Means
- DBSCAN
- Hierarchical Clustering
- Gaussian Mixture Model

---

11. Dimensionality Reduction 차원 축소

차원 축소는 데이터의 정보는 최대한 유지하면서 Feature 개수를 줄이는 방법이다.

Feature가 너무 많으면 모델 학습이 복잡해지고, 시각화하기도 어려워진다.
차원 축소를 사용하면 고차원 데이터를 더 낮은 차원으로 표현할 수 있다.

예시

- 고차원 데이터 시각화
- 노이즈 제거
- 학습 속도 개선
- Feature 압축

대표 알고리즘

- PCA
- t-SNE
- UMAP
- Autoencoder

---

12. Anomaly Detection 이상치 탐지

이상치 탐지는 일반적인 패턴에서 벗어난 데이터를 찾는 방법이다.

정상 데이터가 대부분이고 비정상 데이터가 적은 상황에서 자주 사용된다.

예시

- 이상 거래 탐지
- 제조 공정 불량 탐지
- 네트워크 침입 탐지
- 센서 이상 탐지

대표 알고리즘

- Isolation Forest
- One-Class SVM
- DBSCAN
- Autoencoder

---

13. 지도학습과 비지도학습 비교

구분| 지도학습| 비지도학습
정답 Label| 있음| 없음
목적| 정답 예측| 데이터 구조 탐색
대표 문제| 회귀, 분류| 군집화, 차원 축소
평가 방식| 실제값과 예측값 비교| 군집 품질, 분포, 해석 중심
활용 예시| 이탈 예측, 매출 예측| 고객 세분화, 패턴 탐색

---

14. 사용 상황 비교

상황| 적합한 학습 방식
정답 데이터가 있고 예측이 목적일 때| 지도학습
정답 데이터가 없고 데이터 구조를 알고 싶을 때| 비지도학습
고객을 비슷한 그룹으로 나누고 싶을 때| 비지도학습
고객이 이탈할지 예측하고 싶을 때| 지도학습
매출 금액을 예측하고 싶을 때| 지도학습
고차원 데이터를 시각화하고 싶을 때| 비지도학습

---

15. Semi-supervised Learning 준지도학습

준지도학습은 일부 데이터에만 Label이 있고, 나머지 데이터에는 Label이 없는 경우 사용하는 학습 방법이다.

Label이 있는 데이터와 없는 데이터를 함께 활용하여 모델을 학습한다.

Label을 만드는 비용이 큰 상황에서 사용할 수 있다.

---

16. Reinforcement Learning 강화학습

강화학습은 모델이 환경과 상호작용하면서 보상을 최대화하는 방향으로 행동을 학습하는 방법이다.

지도학습처럼 정답 Label을 직접 주는 것이 아니라, 행동 결과에 대한 보상을 통해 학습한다.

예시

- 게임 AI
- 로봇 제어
- 자율주행
- 추천 시스템 최적화

---

17. 정리

- 지도학습은 정답 Label이 있는 데이터로 학습한다.
- 지도학습의 대표 문제는 회귀와 분류이다.
- 회귀는 연속형 값을 예측하는 문제이다.
- 분류는 정해진 클래스 중 하나를 예측하는 문제이다.
- 비지도학습은 정답 Label 없이 데이터의 구조를 찾는다.
- 비지도학습의 대표 문제는 군집화와 차원 축소이다.
- 군집화는 비슷한 데이터끼리 그룹으로 묶는다.
- 차원 축소는 데이터의 차원을 줄여 표현한다.
- 예측이 목적이면 지도학습, 데이터 탐색과 구조 파악이 목적이면 비지도학습을 고려한다.
