# 00. Preprocessing 개념 정리

## 1. 데이터 전처리 개요

데이터 전처리는 모델 학습 전에 데이터를 분석에 적합한 형태로 정리하고 변환하는 과정이다.

원본 데이터에는 결측치, 중복값, 이상치, 범주형 변수, 서로 다른 스케일의 값 등이 포함될 수 있다. 이를 그대로 사용하면 모델 성능이 떨어지거나 학습이 불안정해질 수 있다.

대표적인 전처리 과정은 다음과 같다.

- 데이터 클렌징
- 데이터 인코딩
- 데이터 스케일링
- 특성 공학

---

## 2. 데이터 클렌징

데이터 클렌징은 결측치, 중복값, 이상치 등을 처리해 데이터 품질을 높이는 과정이다.

### 2.1. 결측치 처리

결측치는 데이터가 비어 있는 값을 의미한다. 처리 방법은 크게 제거와 대체로 나뉜다.

#### 제거

- 결측치가 있는 행을 삭제한다.
- 결측치가 많은 열을 삭제한다.
- 결측치가 적고 삭제해도 분석에 큰 영향이 없을 때 사용한다.

#### 대체

결측치를 특정 값으로 채운다.

- 평균값: 수치형 데이터에 사용
- 중앙값: 이상치가 있는 수치형 데이터에 사용
- 최빈값: 범주형 데이터에 사용
- 특정 값: `0`, `Unknown`, 기타 의미 있는 값으로 대체

### 2.2. 중복값 처리

중복값은 동일한 데이터가 반복되어 존재하는 경우를 말한다.

중복 데이터가 많으면 모델이 특정 패턴을 과도하게 학습할 수 있으므로 필요에 따라 제거한다.

### 2.3. 이상치 처리

이상치는 일반적인 데이터 범위에서 크게 벗어난 값이다.

이상치는 실제로 의미 있는 값일 수도 있고 입력 오류일 수도 있으므로, 무조건 제거하기보다 데이터의 의미를 확인한 뒤 처리한다.

대표적인 처리 방법은 다음과 같다.

- 제거
- 평균 또는 중앙값으로 대체
- 상한값 또는 하한값으로 조정
- 로그 변환 등으로 분포 완화

---

## 3. 데이터 인코딩

인코딩은 범주형 데이터를 모델이 학습할 수 있는 숫자 형태로 변환하는 과정이다. 대부분의 머신러닝 모델은 문자 데이터를 직접 처리하지 못하므로 범주형 변수를 숫자로 바꿔야 한다.

### 3.1. Label Encoding

Label Encoding은 각 범주에 하나의 정수값을 부여하는 방식이다.

| 원본 값 | 변환 값 |
| ------- | ------: |
| blue    |       0 |
| green   |       1 |
| red     |       2 |

#### 특징

- 범주마다 하나의 정수값을 부여한다.
- 변환 결과가 간단하고 메모리 사용량이 적다.
- 숫자 크기 관계가 생길 수 있어 주의가 필요하다.
- 순서가 있는 범주형 변수나 트리 기반 모델에 사용할 수 있다.

예를 들어 `red = 2`, `blue = 0`은 `red`가 `blue`보다 크다는 의미가 아니다. 하지만 일부 모델은 이를 크기 관계로 해석할 수 있다.

### 3.2. One-hot Encoding

One-hot Encoding은 각 범주를 새로운 열로 만들고, 해당 범주에만 `1`을 표시하는 방식이다.

| color | color_blue | color_green | color_red |
| ----- | ---------: | ----------: | --------: |
| blue  |          1 |           0 |         0 |
| green |          0 |           1 |         0 |
| red   |          0 |           0 |         1 |

#### 특징

- 범주를 독립적인 열로 표현한다.
- 범주 간 순서나 크기 관계가 생기지 않는다.
- 명목형 변수에 적합하다.
- 범주 수가 많으면 열 개수가 크게 증가한다.

### 3.3. 인코딩 방식 비교

| 구분 | Label Encoding | One-hot Encoding |
| ---- | -------------- | ---------------- |
| 변환 방식 | 범주를 정수로 변환 | 범주마다 새 열 생성 |
| 장점 | 간단하고 메모리 사용량이 적음 | 순서 관계가 생기지 않음 |
| 단점 | 숫자 크기 관계가 생길 수 있음 | 열 개수가 증가할 수 있음 |
| 적합한 경우 | 순서형 변수, 트리 기반 모델 | 순서가 없는 범주형 변수 |

## 4. 데이터 스케일링

스케일링은 서로 다른 범위의 숫자 데이터를 일정한 기준으로 맞추는 과정이다.

예를 들어 나이는 `0~100` 범위이고 연봉은 수천만 단위라면 두 변수의 스케일 차이가 크다. 이 경우 거리 기반 모델이나 선형 모델에서 특정 변수가 과도한 영향을 줄 수 있다.

스케일링이 중요한 모델은 다음과 같다.

- KNN
- SVM
- Logistic Regression
- Linear Regression
- PCA
- Neural Network

### 4.1. 표준화 Standardization

표준화는 데이터의 평균을 `0`, 표준편차를 `1`로 변환하는 방식이다.

$$
z = \frac{x - \mu}{\sigma}
$$

- $x$: 원본 값
- $\mu$: 평균
- $\sigma$: 표준편차

#### 특징

- 평균 `0`, 표준편차 `1`의 형태로 변환한다.
- 음수 값이 나올 수 있다.
- 정규분포에 가까운 데이터에 자주 사용한다.
- 선형 모델, SVM, PCA 등에 자주 사용한다.
- 평균과 표준편차를 사용하므로 이상치의 영향을 받을 수 있다.

### 4.2. 정규화 Normalization

정규화는 데이터를 특정 범위로 변환하는 방식이다. 일반적으로 Min-Max Scaling을 의미하며, 값을 `0`과 `1` 사이로 변환한다.

$$
x' = \frac{x - x_{min}}{x_{max} - x_{min}}
$$

#### 특징

- 데이터를 `0~1` 범위로 변환한다.
- 값의 범위가 명확하게 제한된다.
- 거리 기반 알고리즘에서 자주 사용한다.
- 최솟값과 최댓값을 사용하므로 이상치에 민감하다.

### 4.3. Robust Scaling

Robust Scaling은 중앙값과 사분위 범위(IQR)를 사용해 스케일링하는 방식이다.

$$
x' = \frac{x - median}{IQR}
$$

- `median`: 중앙값
- `IQR`: 3사분위수 - 1사분위수

#### 특징

- 중앙값과 IQR을 사용한다.
- 이상치의 영향을 상대적으로 적게 받는다.
- 이상치가 많은 데이터에서 StandardScaler나 MinMaxScaler보다 안정적이다.
- 데이터 분포가 치우쳐 있을 때 유용하다.

### 4.4. 스케일링 방식 비교

| 방법 | 변환 기준 | 특징 | 이상치 영향 |
| ---- | -------- | ---- | ----------- |
| StandardScaler | 평균, 표준편차 | 평균 0, 표준편차 1 | 있음 |
| MinMaxScaler | 최솟값, 최댓값 | 0~1 범위로 변환 | 큼 |
| RobustScaler | 중앙값, IQR | 이상치에 강건 | 적음 |

## 5. 특성 공학 Feature Engineering

특성 공학은 기존 데이터를 바탕으로 모델 학습에 유용한 특성을 만들거나 선택하는 과정이다. 모델 성능은 알고리즘뿐 아니라 어떤 특성을 사용하는지에도 크게 영향을 받는다.

### 5.1. 특성 선택 Feature Selection

특성 선택은 여러 특성 중 모델 학습에 중요한 특성만 고르는 과정이다.

불필요한 특성을 제거하면 모델이 단순해지고 과대적합을 줄일 수 있다.

대표적인 방법은 다음과 같다.

- 상관관계가 높은 변수 제거
- 중요도가 낮은 변수 제거
- 통계적 검정 기반 선택
- Lasso와 같은 규제 모델 사용

### 5.2. 특성 추출 Feature Extraction

특성 추출은 기존 특성을 조합하거나 변환해 새로운 특성을 만드는 과정이다.

예시는 다음과 같다.

- 날짜 데이터에서 연도, 월, 요일 추출
- 텍스트 데이터에서 단어 빈도 추출
- 이미지 데이터에서 주요 패턴 추출
- PCA를 이용한 차원 축소

### 5.3. 특성 가공 Feature Transformation

특성 가공은 기존 값을 모델이 학습하기 좋은 형태로 변환하는 과정이다.

대표적인 방법은 다음과 같다.

- 로그 변환
- 제곱근 변환
- 구간화(Binning)
- 다항 특성 생성
- 비율 변수 생성

### 5.4. 다항 특성 Polynomial Features

다항 특성은 기존 특성을 제곱, 세제곱 또는 특성 간 곱 형태로 확장하는 방법이다.

하나의 특성 $x$가 있을 때 다음과 같은 특성을 추가할 수 있다.

$$
x, x^2, x^3
$$

다항 특성을 사용하면 비선형 관계를 선형 모델로도 표현할 수 있다. 단, 특성이 지나치게 많아지면 과대적합이 발생할 수 있다.

---

## 6. 핵심 정리

- 데이터 전처리는 모델 학습 전에 데이터를 정리하고 변환하는 과정이다.
- 데이터 클렌징은 결측치, 중복값, 이상치를 처리한다.
- 인코딩은 범주형 데이터를 숫자 형태로 변환한다.
- Label Encoding은 간단하지만 숫자 크기 관계가 생길 수 있다.
- One-hot Encoding은 순서 없는 범주형 변수에 적합하지만 열 개수가 증가한다.
- 스케일링은 숫자형 변수의 범위를 맞추는 과정이다.
- StandardScaler는 평균과 표준편차를 사용한다.
- MinMaxScaler는 값을 `0~1` 범위로 변환한다.
- RobustScaler는 중앙값과 IQR을 사용해 이상치 영향을 줄인다.
- 특성 공학은 특성을 선택, 추출, 가공해 모델 성능을 높이는 과정이다.
