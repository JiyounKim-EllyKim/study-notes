Dimensionality Reduction 개념 정리

1. Dimensionality Reduction

Dimensionality Reduction은 데이터의 Feature 개수를 줄이는 방법이다.

한국어로는 차원 축소라고 한다.

데이터의 중요한 정보는 최대한 유지하면서, 불필요하거나 중복되는 Feature를 줄여 더 낮은 차원으로 표현하는 것이 목적이다.

---

2. 차원 축소가 필요한 이유

Feature가 너무 많으면 모델 학습과 해석이 어려워질 수 있다.

차원 축소를 사용하면 다음과 같은 효과를 얻을 수 있다.

- 데이터 시각화가 쉬워진다.
- 학습 속도를 높일 수 있다.
- 노이즈를 줄일 수 있다.
- 중복된 정보를 줄일 수 있다.
- 과대적합을 완화할 수 있다.
- 고차원 데이터의 구조를 더 쉽게 파악할 수 있다.

---

3. 차원의 저주 Curse of Dimensionality

차원의 저주는 Feature 수가 많아질수록 데이터 분석과 모델 학습이 어려워지는 현상이다.

차원이 높아지면 데이터 공간이 매우 넓어지고, 데이터 간 거리가 비슷해지는 문제가 발생할 수 있다.

특히 거리 기반 알고리즘에서 문제가 될 수 있다.

영향을 많이 받는 모델

- KNN
- K-Means
- DBSCAN
- 거리 기반 추천 모델

차원이 높을수록 더 많은 데이터가 필요하고, 모델이 의미 있는 패턴을 찾기 어려워질 수 있다.

---

4. Feature Selection과 Feature Extraction

차원 축소 방법은 크게 Feature Selection과 Feature Extraction으로 나눌 수 있다.

구분| 설명| 예시
Feature Selection| 기존 Feature 중 중요한 것만 선택| 상관관계 기반 변수 선택
Feature Extraction| 기존 Feature를 조합해 새로운 Feature 생성| PCA

Feature Selection은 기존 변수를 그대로 사용하기 때문에 해석이 쉽다.

Feature Extraction은 새로운 축을 만들기 때문에 해석은 어려울 수 있지만, 정보 압축에 효과적이다.

---

5. PCA

PCA는 Principal Component Analysis의 약자로, 대표적인 차원 축소 기법이다.

한국어로는 주성분 분석이라고 한다.

PCA는 데이터의 분산을 최대한 잘 보존하는 새로운 축을 찾아 데이터를 변환한다.

즉, 기존 Feature들을 조합하여 새로운 Feature인 Principal Component를 만든다.

---

6. PCA의 핵심 아이디어

PCA는 데이터가 가장 많이 퍼져 있는 방향을 찾는다.

데이터의 분산이 크다는 것은 그 방향에 정보가 많이 담겨 있다는 의미로 볼 수 있다.

기존 Feature
→ 분산이 큰 방향 찾기
→ 새로운 축 Principal Component 생성
→ 낮은 차원으로 데이터 변환

첫 번째 주성분 PC1은 데이터의 분산을 가장 많이 설명하는 방향이다.
두 번째 주성분 PC2는 PC1과 직교하면서 남은 분산을 가장 많이 설명하는 방향이다.

---

7. Principal Component

Principal Component는 PCA가 새롭게 만든 축이다.

각 Principal Component는 기존 Feature들의 선형 결합으로 만들어진다.

주성분| 의미
PC1| 데이터 분산을 가장 많이 설명하는 첫 번째 축
PC2| PC1 다음으로 분산을 많이 설명하는 두 번째 축
PC3| 그다음으로 분산을 많이 설명하는 축

주성분끼리는 서로 상관이 없도록 만들어진다.

---

8. Explained Variance

Explained Variance는 각 주성분이 전체 데이터의 분산을 얼마나 설명하는지를 나타낸다.

예를 들어 PC1이 전체 분산의 60%, PC2가 25%를 설명한다면, 두 주성분만으로 전체 정보의 85% 정도를 설명한다고 볼 수 있다.

값| 의미
Explained Variance| 주성분이 설명하는 분산의 크기
Explained Variance Ratio| 전체 분산 중 해당 주성분이 설명하는 비율
Cumulative Explained Variance| 누적 설명 분산 비율

PCA에서는 보통 누적 설명 분산 비율을 보고 몇 개의 주성분을 사용할지 결정한다.

---

9. PCA의 과정

PCA는 보통 다음 순서로 진행된다.

1. 데이터를 준비한다.
2. Feature Scaling을 수행한다.
3. 데이터의 분산과 공분산 구조를 확인한다.
4. 분산을 가장 잘 설명하는 주성분을 찾는다.
5. 선택한 주성분 개수만큼 데이터를 변환한다.
6. 변환된 데이터를 시각화하거나 모델 학습에 사용한다.

---

10. PCA와 Scaling

PCA는 Feature의 분산을 기준으로 새로운 축을 찾는다.

따라서 Feature의 단위나 스케일이 다르면 결과가 왜곡될 수 있다.

예를 들어 "나이"와 "연봉"을 함께 사용할 때, 연봉의 숫자 크기가 훨씬 크면 PCA가 연봉 방향의 분산을 더 중요하게 볼 수 있다.

따라서 PCA를 적용하기 전에는 보통 StandardScaler를 사용해 평균 0, 표준편차 1로 스케일링한다.

---

11. PCA의 장점

PCA는 다음과 같은 장점이 있다.

- 고차원 데이터를 낮은 차원으로 압축할 수 있다.
- 데이터 시각화에 사용할 수 있다.
- 중복된 Feature의 정보를 줄일 수 있다.
- 노이즈를 줄이는 효과가 있을 수 있다.
- 모델 학습 속도를 높일 수 있다.
- 주성분끼리 상관이 없도록 변환된다.

---

12. PCA의 한계

PCA에도 한계가 있다.

- 선형 변환 기반이므로 비선형 구조를 잘 표현하지 못할 수 있다.
- 변환된 주성분은 기존 Feature보다 해석이 어렵다.
- Scaling에 민감하다.
- 분산이 큰 방향이 항상 예측에 중요한 방향은 아닐 수 있다.
- Label 정보를 사용하지 않기 때문에 지도학습 문제의 성능 향상을 항상 보장하지 않는다.

---

13. t-SNE

t-SNE는 고차원 데이터를 2차원이나 3차원으로 시각화할 때 자주 사용하는 차원 축소 기법이다.

데이터 간의 가까운 이웃 관계를 보존하는 데 초점을 둔다.

특징

- 고차원 데이터 시각화에 유용하다.
- 복잡한 비선형 구조를 2차원으로 표현할 수 있다.
- 군집 구조를 눈으로 확인하는 데 자주 사용된다.
- 결과 해석 시 전체 거리보다 가까운 이웃 관계를 중심으로 봐야 한다.
- 하이퍼파라미터와 초기값에 따라 결과가 달라질 수 있다.

---

14. UMAP

UMAP은 t-SNE처럼 고차원 데이터를 낮은 차원으로 시각화하는 데 사용되는 기법이다.

t-SNE보다 빠른 경우가 많고, 지역 구조와 전체 구조를 함께 보존하려고 한다.

특징

- 고차원 데이터 시각화에 사용된다.
- t-SNE보다 빠른 경우가 많다.
- 비선형 구조를 표현할 수 있다.
- 군집 구조 확인에 유용하다.
- 하이퍼파라미터 설정에 따라 결과가 달라질 수 있다.

---

15. PCA, t-SNE, UMAP 비교

기법| 특징| 주요 목적
PCA| 선형 차원 축소| 정보 압축, 전처리, 시각화
t-SNE| 비선형 차원 축소| 고차원 데이터 시각화
UMAP| 비선형 차원 축소| 고차원 데이터 시각화, 구조 파악

PCA는 모델 학습 전 전처리나 정보 압축에 사용할 수 있다.

t-SNE와 UMAP은 주로 데이터 구조를 시각적으로 확인하기 위해 사용한다.

---

16. Autoencoder

Autoencoder는 신경망을 이용한 차원 축소 방법이다.

입력 데이터를 더 낮은 차원의 벡터로 압축한 뒤, 다시 원래 데이터로 복원하도록 학습한다.

Input
→ Encoder
→ Latent Vector
→ Decoder
→ Reconstructed Input

- Encoder: 입력 데이터를 낮은 차원으로 압축
- Latent Vector: 압축된 표현
- Decoder: 압축된 표현을 다시 원래 형태로 복원

Autoencoder는 비선형 차원 축소가 가능하다는 장점이 있다.

---

17. 차원 축소 활용 예시

차원 축소는 다양한 상황에서 사용할 수 있다.

활용| 설명
데이터 시각화| 고차원 데이터를 2D 또는 3D로 표현
노이즈 제거| 중요하지 않은 변동을 줄임
학습 속도 개선| Feature 수를 줄여 계산량 감소
군집 구조 확인| Clustering 전후 데이터 구조 확인
압축 표현 학습| Autoencoder로 저차원 표현 생성

---

18. 차원 축소 사용 시 주의할 점

- 차원 축소 과정에서 정보 손실이 발생할 수 있다.
- PCA는 Scaling에 민감하다.
- t-SNE와 UMAP 결과는 시각화 목적에 가깝고, 거리 해석에 주의해야 한다.
- 차원 축소 후 성능이 항상 좋아지는 것은 아니다.
- 지도학습 문제에서는 차원 축소 전후의 검증 성능을 비교해야 한다.
- 해석 가능성이 중요한 문제에서는 Feature Selection이 더 적합할 수 있다.

---

19. 정리

- Dimensionality Reduction은 Feature 개수를 줄이는 방법이다.
- 차원 축소는 시각화, 노이즈 제거, 학습 속도 개선, 과대적합 완화에 활용할 수 있다.
- 차원의 저주는 Feature가 많아질수록 분석과 학습이 어려워지는 현상이다.
- Feature Selection은 기존 Feature 중 중요한 변수를 선택하는 방법이다.
- Feature Extraction은 기존 Feature를 조합해 새로운 Feature를 만드는 방법이다.
- PCA는 분산을 최대한 보존하는 방향으로 데이터를 변환한다.
- PCA를 적용하기 전에는 Scaling이 중요하다.
- Explained Variance를 통해 주성분이 정보를 얼마나 설명하는지 확인할 수 있다.
- t-SNE와 UMAP은 고차원 데이터 시각화에 자주 사용된다.
- Autoencoder는 신경망 기반의 비선형 차원 축소 방법이다.
