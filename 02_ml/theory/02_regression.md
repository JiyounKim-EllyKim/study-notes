# Regression 개념 정리

## 0. 회귀 모델 개요

회귀 모델은 입력 데이터의 특성을 바탕으로 연속형 값을 예측하는 모델이다.

예시:
- 주택 가격 예측
- 매출액 예측
- 기온 예측
- 시험 점수 예측
- 수요량 예측

---

## 1. KNN Regression

KNN 회귀는 새로운 데이터와 가장 가까운 k개의 이웃을 찾고, 그 이웃들의 실제값 평균을 예측값으로 사용하는 모델이다.

분류에서는 이웃들의 클래스를 기준으로 다수결을 수행하지만, 회귀에서는 이웃들의 y값 평균을 사용한다.

### 특징

- 거리 기반 모델이다.
- 데이터 스케일에 민감하다.
- 학습 과정은 거의 없고, 예측 시점에 주변 데이터를 탐색한다.
- 데이터가 많아질수록 예측 시간이 오래 걸릴 수 있다.
- 학습 데이터 범위를 벗어나는 값은 잘 예측하지 못한다.

| k값 | 특징 |
|---|---|
| 작음 | 주변 데이터에 민감, variance 증가, 과대적합 가능 |
| 큼 | 전체 경향 반영, bias 증가, 과소적합 가능 |

---

## 2. Linear Regression

Linear Regression은 독립 변수와 종속 변수 사이의 선형 관계를 모델링하는 방법이다.

### 2.1. Simple Linear Regression

독립 변수가 하나인 선형 회귀 모델이다.

$$
y = wx + b
$$

### 2.2. Multiple Linear Regression

독립 변수가 여러 개인 선형 회귀 모델이다.

$$
y = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b
$$

---

## 3. Non-Linear Regression

비선형 회귀는 데이터의 관계가 직선이 아닌 곡선 형태일 때 사용하는 회귀 방식이다.

### 3.1. 지수 회귀

값이 기하급수적으로 증가하거나 감소하는 패턴에 사용한다.

$$
y = a \times e^{bx}
$$

예시:
- 인구 성장
- 바이러스 전파
- 방사능 붕괴

### 3.2. 로그 회귀

처음에는 빠르게 증가하다가 점점 증가 속도가 느려지는 패턴에 사용한다.

$$
y = a + b \times \log(x)
$$

예시:
- 학습 효과 곡선
- 마케팅 비용 대비 수익
- 광고 효과 분석

### 3.3. 다항 회귀

독립 변수를 2차, 3차 이상의 다항식으로 변환하여 회귀를 수행하는 방법이다.

$$
y = w_1x + w_2x^2 + b
$$

`PolynomialFeatures`를 사용해 기존 특성을 다항식 형태로 변환할 수 있다.

다항 회귀는 곡선 관계를 표현할 수 있지만, 차수가 너무 높아지면 과대적합이 발생하기 쉽다.

---

## 4. Regularized Linear Models

규제 선형 회귀는 비용 함수에 회귀 계수의 크기에 대한 패널티를 추가하여 과대적합을 줄이는 방법이다.

모델이 복잡해지거나 회귀 계수가 지나치게 커지면 학습 데이터에는 잘 맞지만 새로운 데이터에 대한 예측 성능이 떨어질 수 있다.

$$
\text{비용함수 목표} = \min \left( \text{RSS}(w) + \alpha \times W \right)
$$

- RSS: 실제값과 예측값의 차이를 제곱하여 더한 값
- $\alpha$: 규제 강도를 조절하는 하이퍼파라미터
- $W$: 회귀 계수에 부여하는 규제 항

$\alpha$가 클수록 규제가 강해지고, 작을수록 규제가 약해진다.

---

## 5. Ridge, Lasso, Elastic Net

### 5.1. Ridge Regression

Ridge는 L2 규제를 적용한 선형 회귀 모델이다.

$$
\text{MSE} + \alpha \sum w_i^2
$$

특징:
- 계수의 제곱합에 패널티를 부여한다.
- 모든 계수를 0에 가깝게 줄인다.
- 계수를 정확히 0으로 만들지는 않는다.
- 대부분의 피처가 의미 있을 때 적합하다.

---

### 5.2. Lasso Regression

Lasso는 L1 규제를 적용한 선형 회귀 모델이다.

$$
\text{MSE} + \alpha \sum |w_i|
$$

특징:
- 계수의 절댓값 합에 패널티를 부여한다.
- 일부 계수를 정확히 0으로 만들 수 있다.
- 불필요한 피처를 제거하는 효과가 있다.
- 피처 선택이 필요할 때 적합하다.

---

### 5.3. Elastic Net

Elastic Net은 L1 규제와 L2 규제를 함께 사용하는 모델이다.

$$
\text{MSE} + \alpha \left( r \sum |w_i| + \frac{1-r}{2} \sum w_i^2 \right)
$$

- `l1_ratio = 1`: Lasso와 동일
- `l1_ratio = 0`: Ridge와 동일
- `0 < l1_ratio < 1`: L1 규제와 L2 규제를 함께 사용

특징:
- L1 규제로 불필요한 피처를 제거할 수 있다.
- L2 규제로 계수를 안정적으로 줄일 수 있다.
- 피처가 많고 상관관계가 높을 때 유용하다.

---

### 5.4. 규제 모델 선택 기준

| 모델 | 규제 방식 | 특징 | 적합한 상황 |
|---|---|---|---|
| Ridge | L2 | 모든 계수를 작게 줄임 | 대부분의 피처가 의미 있을 때 |
| Lasso | L1 | 일부 계수를 0으로 만듦 | 피처 선택이 필요할 때 |
| Elastic Net | L1 + L2 | 피처 선택과 계수 축소를 함께 수행 | 피처가 많고 상관관계가 높을 때 |

---

## 6. 다중공선성 Multicollinearity

다중공선성은 여러 특성 사이의 상관관계가 지나치게 높은 경우를 의미한다.

예를 들어 주택 가격 데이터에서 면적과 방의 크기는 서로 높은 상관관계를 가질 수 있다.

다중공선성이 있으면 모델이 각 특성의 영향을 명확하게 구분하기 어려워지고, 회귀 계수가 불안정하게 추정될 수 있다.

예를 들어 $x_1$과 $x_2$가 거의 같은 정보를 담고 있다면 다음 조합들이 모두 비슷한 예측값을 만들 수 있다.

| w1 | w2 | 조합 |
|---|---|---|
| 3 | 0 | 3x1 + 0x2 |
| 0 | 3 | 0x1 + 3x2 |
| 100 | -97 | 100x1 - 97x2 |

계수가 극단적으로 커져도 서로 상쇄되면서 예측값이 비슷하게 나올 수 있기 때문에, 모델 해석이 어려워지고 과대적합 가능성이 커진다.

### 해결 방법

- 상관관계가 높은 특성 중 일부를 제거한다.
- PCA와 같은 차원 축소 기법을 사용한다.
- Ridge, Lasso, Elastic Net 같은 규제 모델을 사용한다.

---

## 7. 정리

- 회귀 모델은 연속형 값을 예측하는 모델이다.
- KNN 회귀는 가까운 이웃들의 y값 평균을 사용한다.
- 선형 회귀는 독립 변수와 종속 변수 사이의 선형 관계를 모델링한다.
- 비선형 회귀는 곡선 형태의 관계를 표현한다.
- 규제 선형 회귀는 계수의 크기를 제어하여 과대적합을 줄인다.
- Ridge는 모든 계수를 작게 줄인다.
- Lasso는 일부 계수를 0으로 만들어 피처 선택 효과를 가진다.
- Elastic Net은 Ridge와 Lasso의 장점을 결합한 모델이다.
- 다중공선성이 있으면 회귀 계수가 불안정해질 수 있다.
