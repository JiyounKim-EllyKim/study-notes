Regression 개념 정리

1. Regression

Regression은 연속형 값을 예측하는 지도학습 문제이다.

입력 데이터의 특성을 바탕으로 숫자 값을 예측하는 것이 목적이다.

예를 들어 집의 면적, 위치, 방 개수 등을 바탕으로 집값을 예측하는 문제는 회귀 문제에 해당한다.

---

2. Regression 문제 예시

회귀는 예측 결과가 숫자 형태로 나오는 문제에 사용된다.

문제| 예측값
주택 가격 예측| 가격
월 매출 예측| 매출액
기온 예측| 온도
시험 점수 예측| 점수
고객 구매 금액 예측| 금액

예측값은 연속적인 숫자이며, 값의 크기 자체가 의미를 가진다.

---

3. Regression과 Classification 비교

구분| Regression| Classification
예측 대상| 연속형 값| 범주형 클래스
출력 예시| 가격, 매출, 점수| 합격/불합격, 이탈/유지
대표 지표| MAE, MSE, RMSE, R²| Accuracy, Precision, Recall, F1-score
대표 모델| Linear Regression| Logistic Regression

회귀는 숫자를 예측하고, 분류는 클래스를 예측한다.

---

4. Linear Regression 선형 회귀

Linear Regression은 입력 변수와 출력 변수 사이의 선형 관계를 학습하는 회귀 모델이다.

가장 기본적인 회귀 모델이다.

$$
y = wx + b
$$

- $x$: 입력 변수
- $y$: 예측값
- $w$: 가중치
- $b$: 편향

모델은 실제값과 예측값의 차이가 작아지도록 $w$와 $b$를 학습한다.

---

5. Simple Linear Regression 단순 선형 회귀

단순 선형 회귀는 입력 변수가 하나인 선형 회귀이다.

$$
y = wx + b
$$

예를 들어 공부 시간 하나만 사용해서 시험 점수를 예측하는 경우이다.

공부 시간 → 시험 점수

입력 변수 하나와 출력 변수 하나 사이의 관계를 직선으로 설명한다.

---

6. Multiple Linear Regression 다중 선형 회귀

다중 선형 회귀는 입력 변수가 여러 개인 선형 회귀이다.

$$
y = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b
$$

예를 들어 집값을 예측할 때 여러 특성을 함께 사용할 수 있다.

면적, 방 개수, 위치, 건축 연도 → 집값

각 입력 변수는 서로 다른 가중치를 가지며, 모델은 각 변수가 예측값에 미치는 영향을 학습한다.

---

7. Polynomial Regression 다항 회귀

Polynomial Regression은 입력 변수의 거듭제곱 항을 추가하여 비선형 관계를 표현하는 방법이다.

$$
y = w_1x + w_2x^2 + b
$$

선형 회귀 모델을 사용하지만, 입력 변수에 다항식을 추가하여 곡선 형태의 관계를 학습할 수 있다.

특징

- 비선형 패턴을 표현할 수 있다.
- 차수가 높아질수록 모델이 복잡해진다.
- 차수가 너무 높으면 과대적합이 발생할 수 있다.

---

8. 회귀 모델의 학습 목표

회귀 모델의 목표는 실제값과 예측값의 차이를 줄이는 것이다.

이 차이를 오차 Error라고 한다.

$$
Error = y - \hat{y}
$$

- $y$: 실제값
- $\hat{y}$: 예측값

모델은 전체 데이터에서 오차가 작아지도록 학습한다.

---

9. 회귀 손실 함수

회귀 문제에서는 예측값과 실제값의 차이를 측정하기 위해 주로 다음 손실 함수를 사용한다.

손실 함수| 설명
MSE| 오차 제곱의 평균
MAE| 오차 절댓값의 평균

---

9.1. MSE

MSE는 Mean Squared Error의 약자로, 오차를 제곱한 뒤 평균을 구한다.

$$
MSE = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2
$$

특징

- 큰 오차에 더 큰 패널티를 준다.
- 이상치에 민감하다.
- 회귀 모델 학습에서 자주 사용된다.

---

9.2. MAE

MAE는 Mean Absolute Error의 약자로, 오차의 절댓값 평균을 구한다.

$$
MAE = \frac{1}{N} \sum_{i=1}^{N} |y_i - \hat{y}_i|
$$

특징

- 오차 크기를 직관적으로 해석하기 쉽다.
- MSE보다 이상치의 영향을 상대적으로 덜 받는다.
- 실제 평균 오차를 이해하기 좋다.

---

10. 회귀 평가 지표

회귀 모델을 평가할 때는 문제에 맞는 평가 지표를 사용해야 한다.

지표| 설명
MAE| 실제값과 예측값 차이의 절댓값 평균
MSE| 실제값과 예측값 차이의 제곱 평균
RMSE| MSE의 제곱근
R²| 모델이 데이터의 변동성을 얼마나 설명하는지 나타내는 지표

---

10.1. RMSE

RMSE는 Root Mean Squared Error의 약자로, MSE에 제곱근을 씌운 값이다.

$$
RMSE = \sqrt{MSE}
$$

특징

- 예측값과 같은 단위로 해석할 수 있다.
- 큰 오차에 민감하다.
- 회귀 모델 성능 비교에 자주 사용된다.

---

10.2. R² Score

R² Score는 결정계수라고 하며, 모델이 실제값의 변동을 얼마나 잘 설명하는지 나타낸다.

값은 보통 1에 가까울수록 좋다.

R² 값| 의미
1에 가까움| 모델이 데이터를 잘 설명함
0에 가까움| 평균값으로 예측하는 것과 비슷함
음수| 평균값 예측보다 성능이 나쁠 수 있음

---

11. Regularized Regression 정규화 회귀

선형 회귀 모델은 입력 변수가 많거나 변수 간 상관관계가 높을 때 과대적합이 발생할 수 있다.

이를 줄이기 위해 가중치에 패널티를 추가하는 정규화 회귀를 사용할 수 있다.

대표적인 정규화 회귀 모델은 다음과 같다.

- Ridge Regression
- Lasso Regression
- ElasticNet

---

12. Ridge Regression

Ridge Regression은 L2 Regularization을 적용한 선형 회귀 모델이다.

가중치의 제곱합을 손실 함수에 패널티로 추가한다.

$$
Loss = MSE + \lambda \sum w^2
$$

특징

- 가중치가 지나치게 커지는 것을 방지한다.
- 과대적합을 줄일 수 있다.
- 모든 변수를 유지하되 영향력을 줄이는 방식이다.
- 다중공선성이 있을 때 사용할 수 있다.

---

13. Lasso Regression

Lasso Regression은 L1 Regularization을 적용한 선형 회귀 모델이다.

가중치의 절댓값 합을 손실 함수에 패널티로 추가한다.

$$
Loss = MSE + \lambda \sum |w|
$$

특징

- 일부 가중치를 0으로 만들 수 있다.
- 변수 선택 Feature Selection 효과가 있다.
- 불필요한 변수가 많을 때 유용하다.
- 모델을 더 단순하게 만들 수 있다.

---

14. ElasticNet

ElasticNet은 L1 Regularization과 L2 Regularization을 함께 사용하는 회귀 모델이다.

즉, Ridge와 Lasso의 특징을 모두 가진다.

특징

- L1과 L2 패널티를 함께 사용한다.
- 변수 선택과 가중치 축소 효과를 동시에 얻을 수 있다.
- 변수가 많고 서로 상관관계가 있을 때 사용할 수 있다.

---

15. Ridge, Lasso, ElasticNet 비교

모델| 정규화 방식| 특징
Ridge| L2| 가중치를 전체적으로 작게 만듦
Lasso| L1| 일부 가중치를 0으로 만들어 변수 선택 가능
ElasticNet| L1 + L2| Ridge와 Lasso의 장점 결합

---

16. KNN Regression

KNN Regression은 새로운 데이터와 가까운 K개의 이웃 데이터를 기준으로 값을 예측하는 방법이다.

분류에서는 이웃들의 다수결로 클래스를 정하고, 회귀에서는 이웃들의 평균값을 예측값으로 사용한다.

특징

- 학습 과정이 단순하다.
- 데이터의 지역적인 패턴을 반영할 수 있다.
- K 값에 따라 결과가 달라진다.
- 거리 기반 모델이므로 스케일링이 중요하다.

---

17. Tree 기반 회귀 모델

Decision Tree, Random Forest, Gradient Boosting 같은 트리 기반 모델도 회귀 문제에 사용할 수 있다.

특징

- 비선형 관계를 학습할 수 있다.
- 변수 간 복잡한 상호작용을 반영할 수 있다.
- 스케일링의 영향을 상대적으로 덜 받는다.
- 모델에 따라 과대적합을 조절해야 한다.

대표적인 모델은 다음과 같다.

- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor
- XGBoost Regressor
- LightGBM Regressor

---

18. 다중공선성 Multicollinearity

다중공선성은 입력 변수들끼리 강한 상관관계를 가지는 문제이다.

예를 들어 집의 면적과 방 개수가 매우 강하게 관련되어 있다면, 두 변수가 비슷한 정보를 중복해서 제공할 수 있다.

문제점

- 회귀 계수 해석이 어려워질 수 있다.
- 모델이 불안정해질 수 있다.
- 특정 변수의 영향력을 정확히 판단하기 어려울 수 있다.

해결 방법

- 상관관계가 높은 변수 제거
- 변수 선택
- PCA 사용
- Ridge Regression 사용

---

19. 회귀 모델 사용 시 주의할 점

- 예측 대상이 연속형 값인지 확인해야 한다.
- 이상치가 모델 성능에 영향을 줄 수 있다.
- 선형 회귀는 변수 간 선형 관계를 가정한다.
- 변수 스케일이 다른 경우 스케일링이 필요할 수 있다.
- 모델 성능은 MAE, RMSE, R² 등을 함께 확인하는 것이 좋다.
- 평가 지표는 문제 상황에 맞게 선택해야 한다.

---

20. 정리

- Regression은 연속형 값을 예측하는 지도학습 문제이다.
- Linear Regression은 입력 변수와 출력 변수 사이의 선형 관계를 학습한다.
- 단순 선형 회귀는 입력 변수가 하나인 회귀이다.
- 다중 선형 회귀는 입력 변수가 여러 개인 회귀이다.
- Polynomial Regression은 다항식을 사용해 비선형 관계를 표현한다.
- MSE는 큰 오차에 민감하고, MAE는 오차를 직관적으로 해석하기 좋다.
- RMSE는 예측값과 같은 단위로 해석할 수 있다.
- R² Score는 모델이 데이터의 변동성을 얼마나 설명하는지 나타낸다.
- Ridge는 L2 정규화를 사용하고, Lasso는 L1 정규화를 사용한다.
- ElasticNet은 L1과 L2 정규화를 함께 사용한다.
- KNN Regression은 가까운 이웃들의 평균값으로 예측한다.
- 트리 기반 회귀 모델은 비선형 관계를 학습할 수 있다.
