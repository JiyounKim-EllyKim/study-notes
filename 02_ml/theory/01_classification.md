# 01. Classification 개념 정리

## 1. 분류 모델 개요

분류 모델은 입력 데이터를 미리 정의된 클래스나 카테고리 중 하나로 분류하는 모델이다. 종속 변수가 범주형일 때 사용한다.

분류 문제는 클래스 개수에 따라 나눌 수 있다.

- 이진 분류: 클래스가 2개인 경우
  - 예: 스팸/정상 메일, 합격/불합격, 이탈/유지
- 다중 분류: 클래스가 3개 이상인 경우
  - 예: 뉴스 카테고리 분류, 숫자 이미지 분류, 품종 분류

### 1.1. 대표적인 분류 알고리즘

| 알고리즘 | sklearn 클래스 | 핵심 개념 |
| -------- | -------------- | --------- |
| Logistic Regression | `sklearn.linear_model.LogisticRegression` | 선형 결합 값을 확률로 변환해 분류 |
| KNN | `sklearn.neighbors.KNeighborsClassifier` | 가까운 이웃의 클래스를 참고해 분류 |
| Decision Tree | `sklearn.tree.DecisionTreeClassifier` | 조건을 기준으로 데이터를 반복 분할 |
| SVM | `sklearn.svm.SVC` | 클래스 사이의 최적 결정 경계 탐색 |
| Naive Bayes | `sklearn.naive_bayes.GaussianNB` | 베이즈 정리 기반 확률 분류 |

| Gradient Boosting | `sklearn.ensemble.GradientBoostingClassifier` | 이전 모델의 오류를 순차적으로 보완 |

## 2. Logistic Regression

Logistic Regression은 이름에 회귀가 들어가지만, 실제로는 분류 문제에 사용하는 선형 기반 모델이다. 입력 특성의 선형 결합을 계산한 뒤, 그 값을 확률로 변환해 클래스를 예측한다.

#### 특징

- 이진 분류와 다중 분류 모두 지원한다.
- 출력값을 확률로 해석할 수 있다.
- 학습 속도가 빠르고 해석이 비교적 쉽다.
- 데이터가 선형적으로 구분될 때 성능이 좋다.

### 2.1. 기본 원리

먼저 입력 데이터에 대한 선형 결합 값을 계산한다.

$$
z = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b
$$

- $x_i$: 입력 특성
- $w_i$: 가중치
- $b$: 편향
- $z$: 선형 방정식의 결과값

$z$는 그대로 확률로 볼 수 없기 때문에 Sigmoid 함수나 Softmax 함수를 사용해 확률로 변환한다.

### 2.2. Sigmoid Function

Sigmoid 함수는 선형 결합 값 $z$를 `0~1` 사이의 확률값으로 변환한다.

$$
h(z) = \frac{1}{1 + e^{-z}}
$$

#### 특징

- 출력값은 항상 `0~1` 사이다.
- $z$가 커질수록 `1`에 가까워진다.
- $z$가 작아질수록 `0`에 가까워진다.
- $z = 0$이면 $h(z) = 0.5$이다.

이진 분류에서는 보통 `0.5`를 기준으로 클래스를 나눈다.

- $h(z) \geq 0.5$: 클래스 `1`
- $h(z) < 0.5$: 클래스 `0`

### 2.3. 이진 분류 예측 과정

1. 입력 특성으로 선형 결합 값 $z$를 계산한다.
2. $z$를 Sigmoid 함수에 넣어 클래스 `1`의 확률을 계산한다.
3. 클래스 `0`의 확률은 $1 - h(z)$로 계산한다.
4. 기준값 `0.5`를 기준으로 최종 클래스를 예측한다.

예를 들어 $h(z) = 0.8$이면 다음처럼 해석한다.

- 클래스 `1`의 확률: `0.8`
- 클래스 `0`의 확률: `0.2`
- 최종 예측: 클래스 `1`

### 2.4. Softmax Function

다중 분류에서는 클래스가 3개 이상이므로 각 클래스의 확률을 모두 계산해야 한다. 이때 Softmax 함수를 사용한다.

Softmax 함수는 여러 클래스의 점수를 확률로 변환하며, 모든 클래스 확률의 합은 `1`이 된다.

$$
softmax(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}
$$

- $z_i$: i번째 클래스의 점수
- $K$: 전체 클래스 개수
- $e^{z_i}$: i번째 클래스 점수에 지수 함수를 적용한 값

예를 들어 클래스별 점수가 `[2.0, 1.0, 0.1]`이면 Softmax를 통해 다음 확률로 변환할 수 있다.

| 입력값 | Softmax 확률 |
| ------ | -----------: |
| 2.0 | 0.659 |
| 1.0 | 0.242 |
| 0.1 | 0.099 |

가장 높은 확률을 가진 클래스를 최종 예측값으로 선택한다.

### 2.5. Sigmoid와 Softmax 비교

| 구분 | Sigmoid | Softmax |
| ---- | ------- | ------- |
| 사용 목적 | 이진 분류 | 다중 분류 |
| 출력 | 하나의 클래스에 대한 확률 | 각 클래스에 대한 확률 |
| 확률 합 | 반드시 1은 아님 | 전체 합이 1 |
| 예시 | 스팸/정상 | 고양이/강아지/토끼 |

## 3. KNN K-Nearest Neighbors

KNN은 새로운 데이터가 들어왔을 때 가장 가까운 `k`개의 이웃 데이터를 참고해 클래스를 예측하는 모델이다.

예를 들어 `k=5`이면 가장 가까운 5개의 데이터를 찾고, 그중 가장 많이 등장한 클래스로 분류한다.

### 3.1. 특징

- 거리 기반 분류 모델이다.
- 별도의 학습 과정이 거의 없고, 예측 시점에 주변 데이터를 탐색한다.
- 직관적으로 이해하기 쉽다.
- 데이터 스케일에 민감하므로 표준화가 필요할 수 있다.
- 데이터가 많아질수록 예측 시간이 오래 걸릴 수 있다.

### 3.2. k값에 따른 특성

- `k`가 작을수록 모델이 복잡해지고 특정 데이터에 민감해진다.
- `k`가 클수록 모델이 단순해지고 전체적인 경향을 따른다.
- 보통 `k`는 홀수 값을 많이 사용한다.
- `k`가 짝수이면 동률이 발생할 수 있다.

| k값 | 특징 |
| --- | ---- |
| 작음 | bias 낮음, variance 높음, 과대적합 가능성 |
| 큼 | bias 높음, variance 낮음, 과소적합 가능성 |

## 4. Decision Tree

Decision Tree는 조건을 기준으로 데이터를 반복적으로 분할하면서 클래스를 예측하는 모델이다.

트리 구조를 사용하므로 사람이 이해하기 쉽고, 의사결정 규칙처럼 질문을 하나씩 따라가며 데이터를 나누는 방식과 비슷하다.

### 4.1. 특징

- 구조가 직관적이고 해석하기 쉽다.
- 모델의 판단 과정을 시각화할 수 있다.
- 스케일링이나 정규화의 영향을 비교적 적게 받는다.
- 비선형 관계도 어느 정도 표현할 수 있다.
- 트리가 너무 깊어지면 과대적합이 발생하기 쉽다.
- Random Forest, GBM, XGBoost, LightGBM 등 앙상블 모델의 기본 학습기로 자주 사용된다.

### 4.2. 과대적합 제어

Decision Tree는 데이터를 계속 분할하며 학습하므로 제한 없이 성장하면 학습 데이터에 지나치게 맞춰질 수 있다.

과대적합을 줄이는 대표적인 방법은 다음과 같다.

- 트리의 최대 깊이를 제한한다.
- 노드를 분할하기 위한 최소 샘플 수를 지정한다.
- 리프 노드가 가져야 하는 최소 샘플 수를 지정한다.
- 리프 노드의 최대 개수를 제한한다.
- 가지치기(pruning)를 적용한다.

### 4.4. 주요 하이퍼파라미터

| 파라미터 | 설명 |
| -------- | ---- |
| `max_depth` | 트리의 최대 깊이 |
| `min_samples_split` | 내부 노드를 분할하기 위한 최소 샘플 수 |
| `min_samples_leaf` | 리프 노드가 가져야 하는 최소 샘플 수 |
| `max_leaf_nodes` | 리프 노드의 최대 개수 |
| `max_features` | 각 분할에서 고려할 최대 특성 개수 |
| `criterion` | 노드를 분할할 때 사용할 불순도 측정 기준 |
| `ccp_alpha` | 비용 복잡도 가지치기에 사용하는 값 |

#### 주요 파라미터 정리

- `max_depth`: 트리의 최대 깊이를 제한한다. 값이 클수록 복잡해지고 과대적합 가능성이 커진다.
- `min_samples_split`: 노드 분할에 필요한 최소 샘플 수다. 값이 작을수록 더 많이 분할된다.
- `min_samples_leaf`: 리프 노드에 필요한 최소 샘플 수다. 과대적합을 줄이는 데 자주 사용한다.
- `criterion`: 좋은 분할을 판단하는 기준이다. 대표적으로 `gini`, `entropy`가 있다.

### 4.5. 분할 기준

Decision Tree는 데이터를 분할할 때 불순도가 가장 많이 감소하는 기준을 찾는다.

불순도는 하나의 노드 안에 여러 클래스가 얼마나 섞여 있는지를 나타낸다. 불순도가 낮을수록 하나의 클래스가 많이 모여 있는 순수한 노드에 가깝다.

예를 들어 `sugar <= -0.239`라는 조건이 선택되었다면, `sugar` 특성의 여러 기준값 중 `-0.239`로 나눴을 때 불순도 감소가 가장 컸다는 의미다.

즉 Decision Tree는 다음 질문을 반복하며 트리를 만든다.

> 어떤 특성을 어떤 기준값으로 나누면 클래스가 가장 잘 구분될까?

### 4.6. Gini Impurity

지니 불순도는 노드 안에 클래스가 얼마나 섞여 있는지를 측정하는 지표다.

$$
Gini = 1 - \sum_{k=1}^{K} p_k^2
$$

- $K$: 클래스 개수
- $p_k$: 해당 노드에서 k번째 클래스가 차지하는 비율

지니 불순도가 낮을수록 노드가 더 순수하다.

### 4.7. Entropy와 Information Gain

엔트로피는 데이터의 불확실성 또는 혼잡도를 나타내는 지표다.

$$
Entropy = -\sum_{k=1}^{K} p_k \log_2(p_k)
$$

- $K$: 클래스 개수
- $p_k$: 해당 노드에서 k번째 클래스가 차지하는 비율

정보 이득은 분할 전후의 엔트로피 차이를 의미한다. 정보 이득이 클수록 좋은 분할이다.

### 4.8. Variance

분산은 데이터가 평균을 기준으로 얼마나 퍼져 있는지를 나타내는 지표다.

$$
Variance = \frac{\sum (x_i - \mu)^2}{N}
$$

- $x_i$: 각각의 데이터 값
- $\mu$: 평균
- $N$: 데이터 개수

분류 문제에서는 주로 지니 불순도나 엔트로피를 사용하고, 회귀 문제에서는 분산이나 평균제곱오차를 기준으로 분할한다.

### 4.9. 분할 기준 비교

| 측정 방법 | 사용 문제 | 의미 | 분할 기준 |
| -------- | --------- | ---- | --------- |
| Gini Impurity | 분류 | 클래스가 얼마나 섞여 있는지 측정 | 지니 불순도가 낮아지는 방향 |
| Entropy | 분류 | 데이터의 불확실성 측정 | 정보 이득이 커지는 방향 |
| Variance | 회귀 | 데이터의 퍼짐 정도 측정 | 분산이 낮아지는 방향 |

## 5. 핵심 정리

- 분류 모델은 입력 데이터를 미리 정의된 클래스 중 하나로 분류한다.
- Logistic Regression은 선형 결합 값을 확률로 변환해 분류한다.
- Sigmoid는 이진 분류, Softmax는 다중 분류에 사용한다.
- KNN은 가까운 이웃의 클래스를 참고해 분류한다.
- Decision Tree는 조건을 기준으로 데이터를 반복 분할한다.
- 분류 알고리즘은 데이터 특성과 문제 상황에 맞게 선택해야 한다.
