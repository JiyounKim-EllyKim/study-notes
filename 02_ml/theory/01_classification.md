# Classification 개념 정리

## 0. 분류 모델 개요

기계학습의 분류 모델은 주어진 입력 데이터를 미리 정의된 여러 개의 클래스 또는 카테고리 중 하나로 분류하는 모델이다.

분류 모델의 주요 목표는 입력 데이터의 특성을 학습한 뒤, 새로운 데이터가 들어왔을 때 해당 데이터가 어떤 클래스에 속하는지 예측하는 것이다.

분류 모델은 종속 변수가 범주형일 때 사용한다.

예를 들어 다음과 같은 문제들이 분류 문제에 해당한다.

- 이메일이 스팸인지 아닌지 분류
- 고객이 이탈할지 유지될지 예측
- 이미지가 고양이인지 강아지인지 분류
- 환자가 특정 질병을 가지고 있는지 아닌지 예측
- 문서의 카테고리를 정치, 경제, 스포츠 등으로 분류

분류 문제는 클래스의 개수에 따라 크게 두 가지로 나눌 수 있다.

- 이항 분류: 클래스가 2개인 분류 문제
  - 예: 합격 / 불합격, 스팸 / 정상 메일, 이탈 / 유지
- 다항 분류: 클래스가 3개 이상인 분류 문제
  - 예: 뉴스 카테고리 분류, 손글씨 숫자 분류, 품종 분류

## 0.1. 대표적인 분류 알고리즘

### 0.1.1. 로지스틱 회귀 Logistic Regression

`sklearn.linear_model.LogisticRegression`

로지스틱 회귀는 선형 회귀를 분류 문제에 맞게 확장한 모델이다.  
이름에는 회귀가 들어가지만, 실제로는 분류 알고리즘으로 사용된다.

입력 데이터가 특정 클래스에 속할 확률을 계산하고, 그 확률을 기준으로 클래스를 분류한다.

예를 들어 이항 분류에서는 예측 확률이 0.5 이상이면 1번 클래스, 0.5 미만이면 0번 클래스로 분류할 수 있다.

#### 특징

- 이항 분류와 다항 분류에 모두 사용할 수 있다.
- 결과를 확률로 해석할 수 있다.
- 선형 기반 모델이므로 학습 속도가 빠르고 해석이 비교적 쉽다.
- 데이터가 선형적으로 구분될 때 좋은 성능을 낸다.

---

### 0.1.2. 결정 트리 Decision Tree

`sklearn.tree.DecisionTreeClassifier`

결정 트리는 데이터를 여러 조건에 따라 나누면서 분류하는 모델이다.  
질문을 하나씩 던지며 데이터를 분할하는 트리 구조를 가진다.

예를 들어 고객 이탈 예측 문제에서 다음과 같은 방식으로 분류할 수 있다.

- 사용 기간이 1개월 이하인가?
- 최근 접속 횟수가 적은가?
- 결제 금액이 감소했는가?

이러한 조건을 기준으로 데이터를 나누고 최종적으로 클래스를 예측한다.

#### 특징

- 모델 구조를 시각화하기 쉽다.
- 분류 기준을 사람이 이해하기 쉽다.
- 전처리 부담이 비교적 적다.
- 트리가 너무 깊어지면 과대적합이 발생하기 쉽다.

---

### 0.1.3. 서포트 벡터 머신 SVM

`sklearn.svm.SVC`

서포트 벡터 머신은 클래스 사이를 가장 잘 나누는 결정 경계를 찾는 모델이다.  
데이터를 구분하는 경계와 가장 가까운 데이터 포인트들을 서포트 벡터라고 한다.

SVM은 이 서포트 벡터를 기준으로 클래스 사이의 간격이 최대가 되도록 경계를 찾는다.

#### 특징

- 고차원 데이터에서도 좋은 성능을 낼 수 있다.
- 데이터가 선형적으로 구분되지 않을 때는 커널 트릭을 사용할 수 있다.
- 데이터 수가 많아지면 학습 시간이 오래 걸릴 수 있다.
- 스케일에 민감하므로 보통 표준화가 필요하다.

---

### 0.1.4. K-최근접 이웃 KNN

`sklearn.neighbors.KNeighborsClassifier`

KNN은 새로운 데이터가 들어왔을 때, 가장 가까운 k개의 이웃 데이터를 참고하여 클래스를 예측하는 모델이다.

예를 들어 k=5라면 새로운 데이터와 가장 가까운 5개의 데이터를 찾고, 그중 가장 많이 등장한 클래스로 분류한다.

#### 특징

- 학습 과정이 거의 없고, 예측 시점에 주변 데이터를 탐색한다.
- 직관적으로 이해하기 쉽다.
- 거리 기반 모델이므로 스케일에 민감하다.
- 데이터가 많아질수록 예측 시간이 오래 걸릴 수 있다.
- 적절한 k값을 선택하는 것이 중요하다.

---

### 0.1.5. 나이브 베이즈 Naive Bayes

`sklearn.naive_bayes.GaussianNB`

나이브 베이즈는 베이즈 정리를 기반으로 하는 확률 기반 분류 모델이다.  
모든 특성이 서로 독립적이라고 가정하고 분류를 수행한다.

현실에서는 특성들이 완전히 독립인 경우가 많지 않지만, 이 단순한 가정에도 불구하고 특정 문제에서는 좋은 성능을 낸다.

#### 특징

- 학습 속도가 빠르다.
- 적은 데이터에서도 비교적 잘 작동한다.
- 텍스트 분류, 스팸 메일 분류 등에 자주 사용된다.
- 특성 간 독립성을 가정하기 때문에 복잡한 관계를 잘 반영하지 못할 수 있다.

---

### 0.1.6. 랜덤 포레스트 Random Forest

`sklearn.ensemble.RandomForestClassifier`

랜덤 포레스트는 여러 개의 결정 트리를 학습시킨 뒤, 그 결과를 종합하여 최종 예측을 수행하는 앙상블 모델이다.

각 결정 트리가 독립적으로 예측을 수행하고, 분류 문제에서는 다수결 방식으로 최종 클래스를 결정한다.

#### 특징

- 결정 트리보다 과대적합을 줄일 수 있다.
- 여러 트리를 사용하기 때문에 예측이 안정적이다.
- 특성 중요도를 확인할 수 있다.
- 단일 결정 트리보다 해석은 어렵지만, 성능은 일반적으로 더 좋다.

---

### 0.1.7. 그래디언트 부스팅 Gradient Boosting

`sklearn.ensemble.GradientBoostingClassifier`

그래디언트 부스팅은 여러 개의 약한 학습기를 순차적으로 학습하여 강한 모델을 만드는 방법이다.  
앞에서 만든 모델이 틀린 부분을 다음 모델이 보완하는 방식으로 학습이 진행된다.

대표적인 부스팅 계열 모델로는 XGBoost, LightGBM, CatBoost 등이 있다.

#### 특징

- 예측 성능이 높은 편이다.
- 이전 모델의 오류를 보완하면서 학습한다.
- 하이퍼파라미터에 민감하다.
- 학습 시간이 상대적으로 오래 걸릴 수 있다.
- 과대적합을 방지하기 위해 학습률, 트리 깊이, 반복 횟수 등을 조절해야 한다.

### 0.1.8. 가우시안 혼합 모델 Gaussian Mixture Model

`sklearn.mixture.GaussianMixture`

가우시안 혼합 모델은 데이터가 여러 개의 가우시안 분포가 섞여 만들어졌다고 가정하는 모델이다.  
EM 알고리즘을 사용하여 각 분포의 평균, 분산, 가중치 등을 추정한다.

엄밀히 말하면 가우시안 혼합 모델은 주로 분류보다는 군집화에 사용된다.  
하지만 각 데이터가 어떤 분포에 속할 확률을 계산할 수 있기 때문에, 상황에 따라 분류처럼 활용될 수 있다.

#### 특징

- 확률 기반 군집화 모델이다.
- 각 데이터가 특정 그룹에 속할 확률을 계산할 수 있다.
- 데이터가 여러 개의 정규분포 형태로 나뉜다고 가정한다.
- 지도학습 분류 모델이라기보다는 비지도학습 군집화 모델에 가깝다.

## 0.3. 정리

- 분류 모델은 입력 데이터를 미리 정의된 클래스 중 하나로 분류하는 모델이다.
- 종속 변수가 범주형일 때 주로 사용한다.
- 클래스가 2개이면 이항 분류, 3개 이상이면 다항 분류라고 한다.
- 분류 모델은 예측 결과뿐만 아니라 클래스에 속할 확률을 함께 제공하기도 한다.
- 알고리즘마다 장단점이 다르므로 데이터의 특성과 문제 상황에 맞게 선택해야 한다.

## 1. Logistic Regression 로지스틱 회귀

Logistic Regression은 이름에는 회귀가 들어가지만, 실제로는 **분류 문제**에 사용되는 모델이다.

선형 회귀처럼 입력 특성들의 선형 결합을 계산한 뒤, 그 값을 **로지스틱 함수 또는 시그모이드 함수**에 통과시켜 특정 클래스에 속할 확률로 변환한다.

- 회귀식과 로지스틱 함수를 이용하여 분류를 수행하는 모델
- 이진 분류와 다중 분류 모두 지원
- 출력값을 확률로 해석할 수 있음
- 선형 기반 모델이므로 학습 속도가 빠르고 해석이 비교적 쉬움

---

### 1.1. 로지스틱 회귀의 기본 흐름

로지스틱 회귀는 먼저 입력 데이터에 대해 선형 결합 값을 계산한다.

$$
z = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b
$$

여기서 각 기호의 의미는 다음과 같다.

- $x_i$: 입력 특성
- $w_i$: 각 특성에 대한 가중치
- $b$: 절편
- $z$: 선형 방정식의 결과값

이렇게 계산된 $z$는 그대로는 확률로 해석하기 어렵다.  
따라서 $z$를 시그모이드 함수에 넣어 0과 1 사이의 값으로 변환한다.

---

### 1.2. 로지스틱 함수 Logistic Function

로지스틱 함수는 선형 방정식의 출력값을 **확률값**으로 변환해주는 함수이다.  
시그모이드 함수라고도 부른다.

이 함수는 항상 0과 1 사이의 값을 반환하기 때문에, 이진 분류 문제에서 특정 클래스에 속할 확률로 해석할 수 있다.

$$
h(z) = \frac{1}{1 + e^{-z}}
$$

여기서 $z$는 선형 방정식의 결과값이다.

---

### 1.3. 시그모이드 함수의 특징

시그모이드 함수는 S자 형태의 곡선을 가진다.

- 출력값은 항상 0과 1 사이이다.
- $z$가 커질수록 $h(z)$는 1에 가까워진다.
- $z$가 작아질수록 $h(z)$는 0에 가까워진다.
- $z = 0$일 때 $h(z) = 0.5$이다.

수식으로 표현하면 다음과 같다.

$$
z \to \infty \quad \Rightarrow \quad h(z) \to 1
$$

$$
z \to -\infty \quad \Rightarrow \quad h(z) \to 0
$$

---

### 1.4. 로지스틱 회귀에서의 역할

로지스틱 회귀에서는 선형 결합 결과인 $z$를 시그모이드 함수에 넣어 확률값을 계산한다.

예를 들어 이진 분류에서 클래스 1에 속할 확률은 다음과 같이 표현할 수 있다.

$$
P(y=1|x) = h(z)
$$

클래스 0에 속할 확률은 다음과 같다.

$$
P(y=0|x) = 1 - h(z)
$$

따라서 모델은 계산된 확률을 기준으로 클래스를 분류한다.

일반적으로 기준값은 0.5를 사용한다.

- $h(z) \geq 0.5$이면 클래스 1로 분류
- $h(z) < 0.5$이면 클래스 0으로 분류

---

### 1.5. 예측 과정 정리

로지스틱 회귀의 예측 과정은 다음과 같다.

1. 입력 특성들을 이용해 선형 결합 값 $z$를 계산한다.
2. $z$를 시그모이드 함수에 넣어 클래스 1에 속할 확률을 계산한다.
3. 클래스 0에 속할 확률은 $1 - h(z)$로 계산한다.
4. 기준값 0.5를 기준으로 클래스를 분류한다.

예를 들어 시그모이드 함수의 결과가 다음과 같다고 하자.

$$
h(z) = 0.8
$$

그러면 클래스 1에 속할 확률은 0.8, 클래스 0에 속할 확률은 0.2이다.

$$
P(y=1|x) = 0.8
$$

$$
P(y=0|x) = 0.2
$$

이 경우 0.5 이상이므로 클래스 1로 분류한다.

---

### 1.6. 다중 분류에서의 로지스틱 회귀

로지스틱 회귀는 이진 분류뿐만 아니라 다중 분류에도 사용할 수 있다.

다중 분류에서는 여러 클래스 중 하나를 선택해야 하므로, 각 클래스에 속할 확률을 계산한 뒤 가장 높은 확률을 가진 클래스로 분류한다.

예를 들어 손글씨 숫자 분류 문제에서 입력 이미지가 숫자 0부터 9 중 어떤 숫자인지 예측할 수 있다.

| 클래스 | 예측 확률 |
|---|---:|
| 0 | 0.02 |
| 1 | 0.05 |
| 2 | 0.10 |
| 3 | 0.70 |
| 4 | 0.03 |
| 5 | 0.04 |
| 6 | 0.01 |
| 7 | 0.02 |
| 8 | 0.02 |
| 9 | 0.01 |

이 경우 가장 높은 확률을 가진 클래스는 3이므로, 모델은 해당 데이터를 숫자 3으로 분류한다.

### 1.6. 다중 분류와 Softmax 함수

로지스틱 회귀는 이진 분류뿐만 아니라 다중 분류에도 사용할 수 있다.

이진 분류에서는 시그모이드 함수를 사용하여 클래스 1에 속할 확률을 계산한다.  
반면 다중 분류에서는 클래스가 3개 이상이므로, 각 클래스에 속할 확률을 모두 계산해야 한다.

이때 사용하는 함수가 Softmax 함수이다.

---

#### 1.6.1. Softmax 함수

Softmax 함수는 다중 클래스 분류에서 사용하는 함수로, 각 클래스에 대한 점수를 확률로 변환한다.

모델은 각 클래스마다 하나의 점수를 계산한다.  
이 점수들은 그대로는 확률이 아니기 때문에, Softmax 함수를 통해 0과 1 사이의 확률값으로 변환한다.

Softmax 함수를 거친 확률값들은 모두 더하면 1이 된다.

즉, Softmax 함수는 여러 클래스 중 각각의 클래스에 속할 확률을 계산해주는 함수이다.

---

#### 1.6.2. Softmax 함수 정의

클래스가 K개 있을 때, i번째 클래스에 대한 Softmax 확률은 다음과 같이 계산한다.

$$
softmax(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}
$$

각 기호의 의미는 다음과 같다.

- $z_i$: i번째 클래스에 대한 점수
- $e^{z_i}$: i번째 클래스 점수에 지수 함수를 적용한 값
- $\sum_{j=1}^{K} e^{z_j}$: 모든 클래스 점수에 지수 함수를 적용한 뒤 더한 값
- $K$: 전체 클래스 개수

Softmax 함수는 각 클래스 점수에 지수 함수를 적용한 뒤, 전체 합으로 나누어 확률로 변환한다.

---

#### 1.6.3. Softmax 함수가 필요한 이유

다중 분류에서는 여러 클래스 중 하나를 선택해야 한다.

예를 들어 손글씨 숫자 분류 문제에서는 입력 이미지가 0부터 9 중 어떤 숫자인지 예측해야 한다.  
이때 모델은 각 숫자 클래스에 대한 점수를 계산한다.

예를 들어 다음과 같은 점수가 나왔다고 하자.

| 클래스 | 점수 |
|---|---:|
| 고양이 | 2.0 |
| 강아지 | 1.0 |
| 토끼 | 0.1 |

이 점수들은 클래스별 가능성을 나타내지만, 아직 확률은 아니다.  
따라서 Softmax 함수를 사용하여 이 점수들을 확률로 변환한다.

---

#### 1.6.4. Softmax 계산 예시

입력값이 다음과 같다고 하자.

$$
[2.0, 1.0, 0.1]
$$

먼저 각 값에 지수 함수를 적용한다.

$$
e^{2.0} \approx 7.39
$$

$$
e^{1.0} \approx 2.72
$$

$$
e^{0.1} \approx 1.11
$$

그다음 변환된 값들을 모두 더한다.

$$
7.39 + 2.72 + 1.11 = 11.22
$$

마지막으로 각 값을 전체 합으로 나누어 확률을 계산한다.

| 입력값 | 지수 함수 적용 | Softmax 확률 |
|---|---:|---:|
| 2.0 | 7.39 | 7.39 / 11.22 = 0.659 |
| 1.0 | 2.72 | 2.72 / 11.22 = 0.242 |
| 0.1 | 1.11 | 1.11 / 11.22 = 0.099 |

따라서 최종 확률은 다음과 같다.

| 클래스 | 확률 |
|---|---:|
| 첫 번째 클래스 | 65.9% |
| 두 번째 클래스 | 24.2% |
| 세 번째 클래스 | 9.9% |

가장 높은 확률을 가진 클래스는 첫 번째 클래스이므로, 모델은 해당 데이터를 첫 번째 클래스로 분류한다.

---

#### 1.6.5. Softmax 함수의 특징

- 여러 개의 점수를 확률로 변환한다.
- 각 확률값은 0과 1 사이이다.
- 모든 클래스의 확률을 더하면 1이 된다.
- 점수가 큰 클래스일수록 더 높은 확률을 가진다.
- 다중 클래스 분류에서 가장 높은 확률을 가진 클래스를 최종 예측값으로 선택한다.

---

#### 1.6.6. 시그모이드 함수와 Softmax 함수 비교

| 구분 | 시그모이드 함수 | Softmax 함수 |
|---|---|---|
| 사용 목적 | 이진 분류 | 다중 분류 |
| 출력값 | 하나의 클래스에 대한 확률 | 각 클래스에 대한 확률 |
| 확률 합 | 반드시 1이 되지는 않음 | 전체 클래스 확률 합이 1 |
| 예시 | 스팸 / 정상 메일 | 고양이 / 강아지 / 토끼 |

시그모이드 함수는 주로 이진 분류에서 사용하고, Softmax 함수는 다중 분류에서 사용한다.

---

#### 1.6.7. 쉽게 정리

Softmax 함수의 과정은 다음과 같다.

1. 각 클래스에 대한 점수를 계산한다.
2. 각 점수에 지수 함수를 적용한다.
3. 지수 함수가 적용된 값들을 모두 더한다.
4. 각 값을 전체 합으로 나누어 확률로 변환한다.
5. 가장 높은 확률을 가진 클래스를 최종 클래스로 선택한다.

즉, Softmax 함수는 여러 클래스의 점수를 비교하여 상대적으로 가장 가능성이 높은 클래스를 선택할 수 있도록 확률로 바꿔주는 함수이다.

---

### 1.7. 특징 정리

- 로지스틱 회귀는 분류 문제에 사용되는 선형 모델이다.
- 선형 방정식의 결과값을 시그모이드 함수에 넣어 확률로 변환한다.
- 이진 분류에서는 보통 0.5를 기준으로 클래스를 나눈다.
- 출력값을 확률로 해석할 수 있어 결과 해석이 쉽다.
- 선형 기반 모델이므로 학습 속도가 빠르고 비교적 단순하다.
- 데이터가 선형적으로 잘 구분되는 경우 좋은 성능을 낼 수 있다.
- 데이터의 스케일에 영향을 받을 수 있으므로 표준화를 함께 사용하는 경우가 많다.

---

### 1.8. 정리

로지스틱 회귀는 선형 회귀처럼 입력 특성들의 선형 결합을 계산하지만, 그 결과를 그대로 예측값으로 사용하지 않는다.

대신 시그모이드 함수를 사용해 0과 1 사이의 확률값으로 변환하고, 이 확률을 기준으로 클래스를 분류한다.

따라서 로지스틱 회귀는 이름과 달리 회귀 모델이 아니라 **분류 모델**로 사용된다.

## 2. KNN (K-최근접 이웃) 분류 모델
- 데이터 포인트 간의 거리를 기반으로 분류하는 모델
- 보통 k=5를 많이 사용하고, k는 주로 홀수 값을 가진다.
- k=1인 경우는 bias가 작고 variance가 커지고, k=50인 경우는 bias가 크고 variance가 작아지는 문제가 생긴다.
- k가 짝수인 경우, 동률이 나오게 된다면 내부적으로 어느 쪽을 선택할지 미리 정해놓는다. index순일 수도 있고, 더 가까운 거리에 위치한 class를 선택할 수도 있다.

---

## 3. Decision Tree 결정 트리

Decision Tree는 데이터를 여러 조건에 따라 분할하면서 최종 클래스를 예측하는 분류 모델이다.

트리 구조를 사용하기 때문에 사람이 이해하기 쉽고, 마치 스무고개처럼 질문을 하나씩 던지며 데이터를 나누는 방식과 유사하다.

예를 들어 고객 이탈 여부를 예측하는 문제라면 다음과 같은 조건을 기준으로 데이터를 나눌 수 있다.

* 사용 기간이 짧은가?
* 최근 접속 횟수가 적은가?
* 결제 금액이 감소했는가?

이처럼 Decision Tree는 데이터를 가장 잘 구분할 수 있는 기준을 찾아 노드를 분할하고, 최종 리프 노드에서 클래스를 예측한다.

---

### 3.1. Decision Tree의 특징

* 구조가 직관적이어서 이해하기 쉽다.
* 모델의 판단 과정을 시각화하기 쉽다.
* 데이터 스케일링이나 정규화의 영향을 비교적 적게 받는다.
* 수치형 변수와 범주형 변수를 모두 다룰 수 있다.
* 복잡한 규칙 구조를 만들 수 있어 비선형 관계도 어느 정도 표현할 수 있다.
* 트리가 너무 깊어지면 학습 데이터에 지나치게 맞춰져 과대적합이 발생하기 쉽다.

Decision Tree는 단독 모델로도 사용할 수 있지만, Random Forest, GBM, XGBoost, LightGBM, CatBoost 같은 앙상블 모델의 기본 학습기로도 자주 사용된다.

---

### 3.2. Decision Tree와 과대적합

Decision Tree는 데이터를 계속 분할하면서 학습하기 때문에, 제한 없이 트리를 성장시키면 학습 데이터에 지나치게 맞춰질 수 있다.

즉, 학습 데이터에서는 성능이 매우 좋지만 새로운 데이터에서는 성능이 떨어지는 과대적합이 발생할 수 있다.

이를 방지하기 위해 다음과 같은 방법을 사용한다.

* 트리의 최대 깊이를 제한한다.
* 노드를 분할하기 위한 최소 샘플 수를 지정한다.
* 리프 노드가 가져야 하는 최소 샘플 수를 지정한다.
* 리프 노드의 최대 개수를 제한한다.
* 가지치기 pruning을 적용한다.

---

### 3.3. Decision Tree가 앙상블에서 중요한 이유

Decision Tree는 단독으로 사용하면 과대적합이 발생하기 쉽다는 단점이 있다.

하지만 이 단점은 앙상블 기법에서 오히려 장점으로 활용될 수 있다.

앙상블은 여러 개의 약한 학습기를 결합하여 더 강한 모델을 만드는 방법이다.
여기서 약한 학습기란 단독으로는 예측 성능이 아주 높지 않지만, 여러 개를 조합하면 성능을 높일 수 있는 모델을 의미한다.

Decision Tree는 구조가 단순하고 빠르게 학습할 수 있기 때문에 앙상블 모델의 기본 학습기로 많이 사용된다.

대표적인 트리 기반 앙상블 모델은 다음과 같다.

* Random Forest
* Gradient Boosting Machine, GBM
* XGBoost
* LightGBM
* CatBoost

### 3.5. 주요 하이퍼파라미터

Decision Tree의 과대적합을 제어하기 위해 여러 하이퍼파라미터를 조정할 수 있다.

| 파라미터                     | 설명                                                                                                         |
| ------------------------ | ---------------------------------------------------------------------------------------------------------- |
| max_depth                | 트리의 최대 깊이를 지정한다. 값이 클수록 트리가 복잡해지고 과대적합 가능성이 높아진다. 기본값은 None이며, 이 경우 노드가 순수해지거나 더 이상 분할할 수 없을 때까지 트리가 성장한다. |
| max_features             | 각 분할에서 고려할 최대 특성 개수를 지정한다. None이면 모든 특성을 사용한다. sqrt는 전체 특성 수의 제곱근만큼, log2는 log2 값만큼의 특성을 고려한다.             |
| min_samples_split        | 내부 노드를 분할하기 위해 필요한 최소 샘플 수를 지정한다. 값이 작을수록 트리가 더 세밀하게 분할되어 과대적합 가능성이 높아진다.                                  |
| min_samples_leaf         | 리프 노드가 가져야 하는 최소 샘플 수를 지정한다. 값이 작을수록 복잡한 트리가 만들어질 수 있고, 값이 클수록 모델이 단순해진다.                                  |
| max_leaf_nodes           | 리프 노드의 최대 개수를 제한한다. 리프 노드 수를 제한하면 트리의 복잡도를 줄일 수 있다.                                                        |
| criterion                | 노드를 분할할 때 사용할 불순도 측정 기준을 지정한다. 분류에서는 gini, entropy, log_loss 등을 사용할 수 있다.                                  |
| min_weight_fraction_leaf | 리프 노드가 전체 샘플 가중치에서 가져야 하는 최소 비율을 지정한다. 샘플 가중치를 사용하는 경우 과대적합을 줄이는 데 활용할 수 있다.                               |
| ccp_alpha                | 비용 복잡도 가지치기 Cost Complexity Pruning에 사용되는 값이다. 값이 커질수록 더 많은 노드가 가지치기되어 트리가 단순해진다.                          |

---

### 3.6. 주요 하이퍼파라미터 설명

#### max_depth

max_depth는 트리의 최대 깊이를 제한하는 파라미터이다.

* 값이 작을수록 트리가 단순해진다.
* 값이 클수록 더 복잡한 규칙을 학습할 수 있다.
* 너무 크면 과대적합이 발생할 수 있다.
* 너무 작으면 과소적합이 발생할 수 있다.

기본값은 None이다.
None으로 설정하면 모든 리프 노드가 순수해지거나, 더 이상 분할할 수 없을 때까지 트리가 계속 성장한다.

---

#### max_features

max_features는 각 노드에서 최적의 분할을 찾기 위해 고려할 특성의 최대 개수를 지정한다.

* None: 모든 특성을 사용한다.
* int: 지정한 개수만큼의 특성을 사용한다.
* float: 전체 특성 중 지정한 비율만큼 사용한다.
* sqrt: 전체 특성 수의 제곱근만큼 사용한다.
* log2: 전체 특성 수에 log2를 적용한 개수만큼 사용한다.

max_features를 줄이면 각 분할에서 사용하는 특성이 제한되므로 모델의 다양성을 높일 수 있다.
특히 Random Forest 같은 앙상블 모델에서 자주 활용된다.

---

#### min_samples_split

min_samples_split은 내부 노드를 분할하기 위해 필요한 최소 샘플 수를 의미한다.

예를 들어 min_samples_split = 2이면, 어떤 노드에 샘플이 2개 이상 있을 때 분할을 시도할 수 있다.

* 값이 작을수록 트리가 더 많이 분할된다.
* 값이 클수록 트리의 성장이 제한된다.
* 값을 너무 작게 설정하면 과대적합 가능성이 커진다.
* 값을 크게 설정하면 모델이 단순해져 과소적합이 발생할 수 있다.

---

#### min_samples_leaf

min_samples_leaf는 리프 노드가 가져야 하는 최소 샘플 수를 의미한다.

예를 들어 min_samples_leaf = 2이면, 분할 이후 생성되는 각 리프 노드에는 최소 2개 이상의 샘플이 있어야 한다.

* 값이 작을수록 더 세밀한 분할이 가능하다.
* 값이 클수록 트리가 단순해진다.
* 과대적합을 줄이는 데 자주 사용된다.

min_samples_split은 분할을 시작하기 위한 조건이고, min_samples_leaf는 분할 이후 리프 노드가 만족해야 하는 조건이다.

---

#### max_leaf_nodes

max_leaf_nodes는 트리가 가질 수 있는 리프 노드의 최대 개수를 제한한다.

리프 노드가 많아질수록 트리는 더 복잡해지고, 학습 데이터에 더 세밀하게 맞춰질 수 있다.
따라서 리프 노드 수를 제한하면 과대적합을 줄일 수 있다.

---

#### criterion

criterion은 노드를 분할할 때 어떤 기준으로 좋은 분할을 판단할지 정하는 파라미터이다.

분류 문제에서는 주로 다음 기준을 사용한다.

* gini: 지니 불순도를 기준으로 분할한다.
* entropy: 엔트로피와 정보 이득을 기준으로 분할한다.
* log_loss: 로그 손실을 기준으로 분할한다.

기본값은 보통 gini이다.

---

### 3.7. 정보 균일도 측정 방법

Decision Tree는 노드를 분할할 때 데이터가 더 균일해지는 방향으로 분할한다.

즉, 하나의 노드 안에 여러 클래스가 섞여 있는 상태보다, 분할 후 각 노드에 하나의 클래스가 많이 모이도록 만드는 것이 목표이다.

이때 데이터의 혼잡도 또는 불순도를 측정하는 대표적인 방법으로 지니 불순도와 엔트로피가 있다.

---

### 3.8. 지니 불순도 Gini Impurity

지니 불순도는 한 노드 안에 서로 다른 클래스가 얼마나 섞여 있는지를 나타내는 지표이다.

지니 불순도가 낮을수록 데이터가 한 클래스에 가깝게 모여 있다는 뜻이다.
즉, 노드의 순도가 높다고 볼 수 있다.

지니 불순도는 다음과 같이 계산한다.

$$
Gini = 1 - \sum_{k=1}^{K} p_k^2
$$

* K: 클래스의 개수
* p_k: 해당 노드에서 k번째 클래스가 차지하는 비율

예를 들어 어떤 노드에 클래스 0과 클래스 1이 각각 50%씩 섞여 있다면 지니 불순도는 높다.
반대로 한 클래스가 대부분을 차지하면 지니 불순도는 낮아진다.

Decision Tree는 분할 이후 자식 노드의 지니 불순도가 낮아지는 방향으로 데이터를 나눈다.

---

### 3.9. 엔트로피 Entropy와 정보 이득 Information Gain

엔트로피는 데이터의 혼잡도 또는 불확실성을 나타내는 지표이다.

엔트로피가 높다는 것은 한 노드 안에 여러 클래스가 섞여 있어 불확실성이 크다는 뜻이다.
엔트로피가 낮다는 것은 특정 클래스가 많이 모여 있어 불확실성이 작다는 뜻이다.

엔트로피는 다음과 같이 계산한다.

$$
Entropy = -\sum_{k=1}^{K} p_k \log_2(p_k)
$$

* K: 클래스의 개수
* p_k: 해당 노드에서 k번째 클래스가 차지하는 비율

정보 이득은 부모 노드의 엔트로피와 자식 노드의 엔트로피 차이를 의미한다.

즉, 어떤 기준으로 분할했을 때 엔트로피가 얼마나 감소했는지를 나타낸다.

정보 이득이 클수록 좋은 분할이라고 볼 수 있다.

Decision Tree는 정보 이득이 큰 방향으로 데이터를 분할할 수 있다.

---

### 3.10. 분산도 Variance

분산도는 데이터가 평균을 기준으로 얼마나 퍼져 있는지를 나타내는 지표이다.

분류 문제에서는 주로 지니 불순도나 엔트로피를 사용하고, 회귀 문제에서는 분산이나 평균제곱오차를 기준으로 분할한다.

분산은 다음과 같이 계산한다.

$$
Variance = \frac{\sum (x_i - \mu)^2}{N}
$$

* x_i: 각각의 데이터 값
* μ: 평균
* N: 데이터 개수

회귀 트리는 분할 이후 자식 노드의 분산이 낮아지는 방향으로 데이터를 나눈다.

---

### 3.11. 분할 기준 정리

| 측정 방법  | 사용 문제 | 설명                          | 분할 기준                  |
| ------ | ----- | --------------------------- | ---------------------- |
| 지니 불순도 | 분류    | 노드 안에 클래스가 얼마나 섞여 있는지 측정    | 자식 노드의 지니 불순도가 낮아지는 방향 |
| 엔트로피   | 분류    | 데이터의 불확실성 또는 혼잡도 측정         | 정보 이득이 커지는 방향          |
| 분산도    | 회귀    | 데이터가 평균을 기준으로 얼마나 퍼져 있는지 측정 | 자식 노드의 분산이 낮아지는 방향     |

---

### 3.12. 정리

* Decision Tree는 조건을 기준으로 데이터를 반복적으로 분할하는 모델이다.
* 스무고개처럼 질문을 하나씩 던지며 최종 클래스를 예측한다.
* 데이터 스케일링이나 정규화의 영향을 비교적 적게 받는다.
* 구조가 직관적이어서 해석하기 쉽다.
* 트리가 너무 깊어지면 과대적합이 발생하기 쉽다.
* 과대적합을 줄이기 위해 max_depth, min_samples_split, min_samples_leaf, max_leaf_nodes 등을 조절한다.
* 분류 문제에서는 주로 지니 불순도와 엔트로피를 기준으로 분할한다.
* 회귀 문제에서는 분산이나 평균제곱오차를 기준으로 분할한다.
* Decision Tree는 Random Forest, GBM, XGBoost, LightGBM 같은 앙상블 모델의 기본 학습기로 자주 사용된다.
